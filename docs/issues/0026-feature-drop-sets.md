# ドロップセットの段と制約を実装する

- Requirements: REQ-SET-003
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-drop-sets

## 目的

ドロップセットを、1 つのセットの中に重量と回数の組を複数段記録できるようにする。
記録画面では、ドロップセットの行を直前のセットに続く段として表示する。
先頭の行と、ウォームアップセットの直後の行では、ドロップセットを選べないようにする。

## 優先度根拠

ドロップセットは記録のデータの形に関わり、総重量と自己ベストの計算を変える。
段の制約を保存の時点で検査しないと、画面の操作を経ない保存で不正な記録が入る。

## 現状

0025 でセットの追加、削除、重量と回数、セット種別を実装する。
しかし、ドロップセットの段、段の追加と削除、先頭とウォームアップの直後の制約、段ごとの表示がない。

## 設計方針

ドロップセットは、1 つのセットの中に順序を持つ段を持つ。
段は、重量、回数、反動の回数、補助の回数、左右の値を持つ。
左右別の種目では、左右それぞれの値を持つ。左右別の記録は 0027 が担う。
この issue では、左右別でない種目の段を実装する。

記録画面では、段を 1 行ずつ表示する。
ドロップセットの行は、セット番号の代わりに `D` を表示する。
ドロップセットの行は、直前のセットに続く段として扱う。
ドロップセットの RPE は、段の行ではなく親セットに 1 つ持つ。入力は 0028 が担う。

先頭の行と、ウォームアップセットの直後の行では、ドロップセットを選べない。
この制約を、画面の操作とサーバーの保存の両方で検査する。
画面だけの検査にすると、同期の経路が増えたときに制約が破れる。

ドロップセットの段の追加と削除ができる。
段が 1 つだけのドロップセットは、通常のセットと同じ値を持つが、セット種別はドロップセットのままとする。
段をすべて削除した場合は、セット自体を削除する。

集計は 0012 に従う。
最大重量と推定 1RM の自己ベストは最初の段だけを対象にし、種目別の総重量の自己ベストは全段を対象にし、部位別のセット数は 1 と数える。
画面の行数と記録のセット数は一致しないため、セット数の集計は画面の行数ではなく記録のセット数で行う。

## 完了条件

- [ ] ドロップセットにした行に、重量と回数の組を複数段追加できる。これは REQ-SET-003 の受入基準に対応する。
- [ ] 記録画面で、ドロップセットの行が直前のセットに続く段として表示される。これは REQ-SET-003 の受入基準に対応する。
- [ ] 先頭の行とウォームアップセットの直後の行では、ドロップセットを選べない。画面とサーバーの両方で拒否する。これは REQ-SET-003 の受入基準に対応する。
- [ ] ドロップセットの行に `D` が表示され、セット番号が振られない。
- [ ] ドロップセットの RPE が、段の行ではなく親セットに 1 つ保存される。
- [ ] 段の追加と削除が、端末内の保存と送信待ちの列を通る。
- [ ] 段をすべて削除すると、セット自体が削除される。
- [ ] 最大重量と推定 1RM の自己ベストが最初の段だけを対象にし、種目別の総重量の自己ベストが全段を対象にし、部位別のセット数が 1 であることを、0012 の計算で確かめる。
- [ ] 画面の行数がセット数と一致しない場合でも、セット数の集計が記録のセット数で行われる。
- [ ] 結合テストで、先頭とウォームアップの直後のドロップセットが 400 になることを確かめる。
- [ ] PBT で、ドロップセットの段の数が変わっても、セット数が 1 であり、総重量と自己ベストの対象が 0012 と一致することを確かめる。
- [ ] 例示テストで、先頭、ウォームアップの直後、通常のセットの直後、ドロップセットの直後の 4 つの位置を確かめる。
- [ ] E2E で、ドロップセットを選び、段を追加し、表示と集計を確かめる。

## 解決方法

`backend/warrior_core/src/set_calc.rs` の `SetSegment` を使い、段の制約を `backend/warrior_core/src/set_rules.rs` に置く。
`backend/warrior/src/set.rs` に段の追加、削除、更新を追加する。
`frontend/src/screens/record.rs` に、ドロップセットの行、`D` の表示、段の追加と削除を置く。
`backend/warrior/tests/e2e_record_drop_set.rs` に E2E を追加する。
`backend/pbt/tests/set_rules.rs` に段の制約と集計の性質テストを置く。
