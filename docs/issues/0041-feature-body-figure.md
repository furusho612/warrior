# 人体図のインライン SVG と部位の色分けを実装する

- Requirements: REQ-LIB-003, REQ-LIB-012
- Priority: Medium
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-body-figure

## 目的

すべての種目に、鍛えられる部位を色で示す人体図を表示し、主働筋と補助筋を区別する。
グリップとアタッチメントに応じて色を変えるのは、研究で違いが確認できたシーテッドロウの手幅の組み合わせに限る。
独自種目は、部位区分をもとに人体図を示す。

## 優先度根拠

人体図は段階 2 の種目ライブラリの理解を助ける機能である。
SVG の属性と筋肉の単位の対応を先に固定しないと、種目のデータと図の色がずれる。

## 現状

`docs/design/assets/body-front.svg` と `body-back.svg` に人体図があり、`docs/design/README.md` に色の指定と属性の書き方がある。
0019 で筋肉の単位と種目の主働筋と補助筋を保存する。
しかし、人体図をアプリに取り込み、種目のデータに応じて色を変える仕組みがない。

## 設計方針

人体図は、前面と背面の SVG をアプリのバンドルに含め、HTML にインラインで描画する。
画像として読み込まない。
ADR-012 は、人体図をインライン SVG で描き、筋肉の単位を `data-primary` と `data-secondary` に空白区切りで設定すると決めている。
この issue はその決定に従う。
`<img>` で読み込むと色を変えられないためである。

種目が持つ主働筋と補助筋の筋肉の単位を、SVG の `data-primary` と `data-secondary` に空白区切りで設定する。
図の要素は、自分の単位がどちらかに含まれる場合に色を変える。
主働筋、補助筋、それ以外の 3 段階の色を保つ。
色は 0005 の生成した CSS カスタムプロパティで指定する。
指定しなければダークの色になる。
ライトのときは、図より外側の要素にライトの値を指定する。

SVG の中の ID は `wfig-` で始める。
前面と背面を同じページに置いても、ID が衝突しないようにする。

独自種目に筋肉の単位がない場合は、部位区分に属する単位をまとめて主働筋として示す。
部位区分がその他の種目は、筋肉の単位を持たないため、図の代わりに全身か下半身かの表示を出す。

グリップとアタッチメントによる色の変更は、PRD の「グリップによる色の変更」の表にある組み合わせだけに適用する。
対象は、シーテッドロウの手幅が狭いアタッチメント、広いアタッチメント、それ以外の 3 つとする。
表にない組み合わせでは、グリップを変えても色を変えない。
ラットプルダウンでは、手幅を変えても色を変えない。

人体図の外に、主働筋と補助筋の名称を表示する。
色だけで部位を示さない。

## 完了条件

- [ ] すべての種目で、鍛えられる部位を色で示す人体図が表示され、主働筋と補助筋が異なる色で区別される。これは REQ-LIB-003 の受入基準に対応する。
- [ ] グリップとアタッチメントで色が変わるのは、シーテッドロウの手幅の組み合わせに限られる。表にない組み合わせでは色が変わらない。これは REQ-LIB-003 の受入基準に対応する。
- [ ] 独自種目では、部位区分に対応する部位が色で示される。これは REQ-LIB-003 の受入基準に対応する。
- [ ] 種目の主働筋と補助筋、人体図の色分け、グリップごとの部位データが、24 個の筋肉の単位で表される。人体図の色分けが、24 個の単位のうち色を付ける部位だけに現れる。これは REQ-LIB-012 の受入基準に対応する。
- [ ] 人体図の SVG の中の ID が `wfig-` で始まり、前面と背面を同じページに置いても衝突しない。
- [ ] ライトとダークの両方で、主働筋と補助筋の区別ができる。
- [ ] 部位区分がその他の種目は、筋肉の単位の色分けではなく、全身か下半身かの表示を出す。
- [ ] 主働筋と補助筋の名称が、図の外に表示される。
- [ ] ブラウザのテストで、24 個の筋肉の単位のそれぞれに対応する SVG の要素があり、`data-primary` と `data-secondary` の値で色が変わることを確かめる。
- [ ] 例示テストで、「グリップによる色の変更」の表の 3 つの組み合わせと、表にない組み合わせを確かめる。
- [ ] PBT で、主働筋と補助筋の単位の集合に対して、色を付ける要素の集合が、その単位の集合と一致することを確かめる。
- [ ] E2E で、種目の詳細を開き、人体図の色と名称が表示されることを確かめる。

## 解決方法

`docs/design/assets/body-front.svg` と `body-back.svg` を `frontend/public/` またはアプリのバンドルに移す。
`frontend/src/body_figure.rs` に、SVG の読み込み、`data-primary` と `data-secondary` の設定、グリップの例外の適用を置く。
`frontend/src/screens/exercise.rs` に人体図と名称を置く。
`frontend/src/text.rs` に筋肉の単位の日本語名と、全身と下半身の文言を追加する。
`frontend/tests/body_figure.rs` にブラウザのテストを追加する。
`backend/pbt/tests/body_figure.rs` に性質テストを置く。
`backend/warrior/tests/e2e_body_figure.rs` に E2E を追加する。
