# 種目の詳細でグリップを選び、人体図の色を確認できるようにする

- Requirements: REQ-LIB-003
- Priority: Medium
- Created: 2026-11-15
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-grip-preview

## 目的

種目の詳細でグリップを選ぶと、人体図の色が変わるようにする。色が変わるのは「グリップによる色の変更」の表の組み合わせだけとする。

## 優先度根拠

REQ-LIB-003 は、グリップとアタッチメントに応じて人体図の色を変えると定める。0041 は色の対応を純粋関数として持つが、利用者がグリップを選ぶ経路がないため、画面では受入基準を満たせない。

## 現状

0041 が `frontend/src/body_figure.rs` にグリップの例外表と `figure_muscles` を置いた。種目の詳細 (`frontend/src/screens/exercise.rs`) はグリップを選ばない図を表示する。記録画面には 0031 がグリップの選択を置いたが、種目の詳細にはない。

## 設計方針

種目の詳細に、その種目が選べるグリップの選択を置く。選択肢は種目スナップショットの `grip_mode` と `grip_options` から作る。初期値は選択肢の先頭とする。
選択を変えると、`figure_muscles` に渡す選択が変わる。色が変わるのは「グリップによる色の変更」の表の組み合わせだけとし、表にない組み合わせでは色を変えない。
グリップを選ばない種目では、選択肢を表示しない。
記録画面の選択肢の組み立ては記録用である。詳細の表示用には、選択肢の組み立てを共有できる関数に寄せる。

## 完了条件

- [ ] 種目の詳細でグリップを選べる。グリップを選ばない種目では選択肢を表示しない。これは REQ-LIB-003 の受入基準のうち、グリップに応じて色を変える条件に対応する。
- [ ] 選んだグリップに応じて図の色が変わり、変わるのは「グリップによる色の変更」の表の組み合わせだけである。これは REQ-LIB-003 の受入基準のうち、色を変える組み合わせを限定する条件に対応する。
- [ ] 例示テストで、表の 3 つの組み合わせと、表にない組み合わせを、画面の選択から確かめる。
- [ ] ブラウザのテストで、選択を変えると色の付く要素が変わることを確かめる。
- [ ] E2E で、シーテッドロウの詳細を開き、手幅を変えると色が変わることを確かめる。

## 解決方法

`frontend/src/screens/exercise.rs` にグリップの選択を置く。
`frontend/src/body_figure.rs` の `figure_muscles` に選んだグリップを渡す。
選択肢の組み立ては、記録画面のものと共有できる形に寄せる。
`backend/warrior/tests/e2e_body_figure.rs` に E2E を追加する。
