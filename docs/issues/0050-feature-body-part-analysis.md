# 部位別のセット数と総重量の分析を実装する

- Requirements: REQ-ANL-005, REQ-ANL-006, REQ-ANL-007
- Priority: Medium
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-body-part-analysis

## 目的

部位区分ごとのセット数と総重量を、週単位と月単位で表示する。
部位間の量の偏りを 1 つのグラフで比較できるようにする。
前の週と前の月との増減を表示する。

## 優先度根拠

部位別の分析は段階 2 の振り返りの機能であり、AI の評価の入力にもなる。
週と月の境界と、セット数と総重量の集計の規則を先に固定しないと、画面と AI で量の判断が食い違う。

## 現状

0011 で日本時間の週と月の境界、0012 で部位別のセット数と総重量、0021 から 0033 で記録を実装する。
しかし、部位別の集計、比較のグラフ、前の週と前の月との増減がない。

## 設計方針

部位区分ごとのセット数と総重量を、週単位と月単位で集計する。
週は日本時間の月曜 0 時に始まり、次の月曜 0 時の直前で終わる。
月は日本時間の 1 日 0 時に始まり、翌月 1 日 0 時の直前で終わる。
0011 の `JstWeek` と `JstMonth` を使う。

集計は、記録時の種目のスナップショットの部位区分を使う。ADR-006 に従い、現在の種目マスターの区分を使わない。
セット数と総重量は 0012 の計算を使う。

- ウォームアップはセット数に数えず、総重量に含めない。
- ドロップセットは 1 セットと数え、総重量には全段を含める。
- 左右別のセットは、総重量を左右の合算とする。
- 時間で記録する種目は、セット数に 1 と数え、総重量に含めない。
- 補助筋として使った部位には数えない。

部位間の量の偏りは、部位区分ごとのセット数または総重量を 1 つのグラフで比較する。
グラフの指標は、セット数と総重量から選ぶ。
グラフはフロントエンドで SVG を描き、集計はサーバーで行う。ADR-016 に従う。

前の週と前の月との増減は、セット数と総重量のそれぞれについて表示する。
増減は、表示中の期間の値から、直前の同じ長さの期間の値を引いた値とする。
週単位の表示では前の週、月単位の表示では前の月とする。

部位区分がその他の種目は、部位別のセット数と総重量に含める。
部位の色は 0005 の生成した部位の色を使う。
ライトとダークの両方で、部位を判別できる色にする。

## 完了条件

- [ ] 部位区分ごとのセット数と総重量が、週単位と月単位で表示される。週と月の境界は日本時間で決まる。これは REQ-ANL-005 の受入基準に対応する。
- [ ] 部位区分ごとのセット数または総重量を、1 つのグラフで比較できる。これは REQ-ANL-006 の受入基準に対応する。
- [ ] 週単位と月単位の表示に、前の週と前の月に対するセット数と総重量の増減が表示される。これは REQ-ANL-007 の受入基準に対応する。
- [ ] 集計が、記録時の種目のスナップショットの部位区分を使う。
- [ ] ウォームアップ、ドロップセット、左右別、時間で記録する種目、補助筋の扱いが 0012 の計算と一致する。
- [ ] 増減が、表示中の期間の値から直前の同じ長さの期間の値を引いた値と一致する。
- [ ] 部位区分がその他の種目が、部位別の集計に含まれる。
- [ ] グラフの指標をセット数と総重量から選べる。
- [ ] ライトとダークの両方で、部位の色を判別できる。
- [ ] PBT で、週単位と月単位の集計が、記録から計算した値と一致し、期間の外の記録を含まないことを確かめる。
- [ ] PBT で、増減が表示中の期間と直前の期間の差と一致することを確かめる。
- [ ] 例示テストで、週の境界の日曜 23:59:59 と月曜 0:00、月末、閏年、空の期間、複数の部位の日を確かめる。
- [ ] E2E で、週単位と月単位を切り替え、指標を切り替え、増減を確かめる。

## 解決方法

`backend/warrior_core/src/body_part_analysis.rs` に、期間の範囲、部位区分ごとのセット数と総重量の集計、増減の計算を置く。
`backend/warrior/src/analysis.rs` に、部位別の分析の取得を置く。
`backend/warrior/src/router.rs` に `GET /api/analysis/body-parts` を追加する。
`frontend/src/screens/analysis.rs` に、週単位と月単位の表示、グラフ、増減を置く。
`frontend/src/graph.rs` に部位別のグラフを追加する。
`backend/warrior/tests/e2e_body_part_analysis.rs` に E2E を追加する。
`backend/pbt/tests/body_part_analysis.rs` に性質テストを置く。
