# レストタイマーと画面の消灯防止を実装する

- Requirements: REQ-TMR-001, REQ-TMR-002, REQ-TMR-003, REQ-TMR-004, REQ-TMR-005, REQ-TMR-006
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-rest-timer

## 目的

レスト時間の既定値、種目ごととセットごとの上書きを設定できるようにする。
セットの完了と同時にタイマーを起動し、残り時間の表示、延長、短縮、スキップ、終了の音と画面表示、振動を実装する。
別のタブやアプリから戻ったときに、経過時間を反映した正しい残り時間を表示する。
記録中は画面が自動で消灯しないようにする。

## 優先度根拠

レストタイマーは段階 1 の記録の中核であり、セットの完了の直後に必ず動く。
残り時間を減算する状態で持つと、バックグラウンドや再読み込みで残り時間がずれる。

## 現状

0025 から 0033 でセットの記録を実装するが、レスト時間の設定、タイマーの起動、残り時間の表示、延長と短縮とスキップ、音と画面表示、振動、画面の消灯防止がない。

## 設計方針

レスト時間は、全体の既定値、種目ごとの値、セットごとの値を持つ。
ADR-007 は、セットの完了時にレストの終了予定時刻を決めて保存し、残り時間を表示のたびに終了予定時刻と現在時刻の差から計算すると決めている。
この issue はその決定に従う。
セットの指定が種目の指定より優先し、種目の指定が全体の既定値より優先する。
指定がない場合は全体の既定値を使う。

セットを完了した時点で、レストの終了予定時刻を決めて保存する。
残り時間は、表示のたびに終了予定時刻と現在時刻の差から計算する。
残り時間を減算する状態として持たない。
一定間隔の処理は画面の再描画にだけ使う。

タブの表示が戻ったとき、利用者がページを再読み込みしたとき、画面を描き直すたびに、終了予定時刻から残り時間を計算する。
終了予定時刻を過ぎていれば、タイマーは終了したものとして扱う。

延長と短縮は終了予定時刻を変更する。
スキップはタイマーを終了する。
記録中のトレーニングが持つレストタイマーは 1 つとする。
種目を切り替えても、タイマーは続く。
スーパーセットでは、組の最後の種目のセットを完了したときに起動する。

残り時間が 0 になると、音を鳴らし、画面に終了の表示を出す。
振動に対応する端末では、同じときに振動する。
音は利用者の操作の後に再生を開始できるようにする。ブラウザが自動再生を止める場合は、画面の表示で知らせる。

記録中は、画面の自動消灯を防ぐ。
ブラウザの Wake Lock の API を使い、画面が隠れた後に戻ったら取り直す。
利用者が設定で無効にした場合は、端末の通常の消灯に戻す。設定の保存は 0062 が担う。

終了予定時刻は端末内に保存し、送信待ちの列を通してサーバーにも保存する。
再読み込みの後も、保存した終了予定時刻からタイマーを続ける。
プッシュ通知の予約は 0037 が担う。

## 完了条件

- [ ] レスト時間の既定値を設定できる。種目ごととセットごとに別のレスト時間を指定すると、その種目またはセットにだけ指定した値を使い、ほかの種目とセットには既定値を使う。セットの指定が種目の指定より優先される。これは REQ-TMR-001 の受入基準に対応する。
- [ ] セットを完了にすると、同じ操作でレストタイマーが起動し、残り時間の表示が始まる。これは REQ-TMR-002 の受入基準に対応する。
- [ ] タイマーに残り時間が表示される。延長と短縮の操作で残り時間が変わり、スキップでタイマーが終了する。これは REQ-TMR-003 の受入基準に対応する。
- [ ] 残り時間が 0 になると、音が鳴り、画面に終了の表示が出る。振動に対応する端末では、同じときに振動も起きる。これは REQ-TMR-004 の受入基準に対応する。
- [ ] 記録中は画面の自動消灯が起きない状態を保つ。設定で無効にすると、端末の通常の消灯に戻る。これは REQ-TMR-005 の受入基準に対応する。
- [ ] タイマーの動作中に別のタブへ移り、終了予定時刻より前に戻ると、経過時間を引いた残り時間が表示される。終了予定時刻を過ぎてから戻ると、終了した状態が表示される。これは REQ-TMR-006 の受入基準に対応する。
- [ ] 再読み込みの後も、保存した終了予定時刻からタイマーが続く。
- [ ] 種目を切り替えてもタイマーが続き、記録中のトレーニングにタイマーが 1 つだけである。
- [ ] スーパーセットの最後の種目のセットを完了したときにだけ、タイマーが起動する。
- [ ] 画面が隠れた後に戻ったとき、Wake Lock を取り直す。
- [ ] PBT で、任意の終了予定時刻と現在時刻に対して、残り時間が 0 以上で、終了予定時刻を過ぎた場合は 0 になることを確かめる。
- [ ] PBT で、延長と短縮が終了予定時刻だけを変え、残り時間の計算が同じ規則であることを確かめる。
- [ ] 例示テストで、セットの指定、種目の指定、既定値の優先順位、終了予定時刻ちょうど、1 秒前、1 秒後を確かめる。
- [ ] ブラウザのテストで、Wake Lock の要求と取り直し、音と振動の呼び出しを確かめる。
- [ ] E2E で、セットを完了してタイマーを起動し、延長、短縮、スキップ、別のタブからの復帰、終了の表示を確かめる。

## 解決方法

`backend/warrior_core/src/rest_timer.rs` に、レスト時間の選択、終了予定時刻、残り時間、延長と短縮の計算を置く。
`backend/warrior/src/rest_timer.rs` に、終了予定時刻の保存を置く。
`frontend/src/screens/record.rs` に、下に固定するタイマーの表示と操作を置く。
`frontend/src/wake_lock.rs` に、Wake Lock の要求と取り直しを置く。
`frontend/src/sound.rs` に、終了の音と振動を置く。
`frontend/tests/rest_timer.rs` にブラウザのテストを追加する。
`backend/warrior/tests/e2e_rest_timer.rs` に E2E を追加する。
`backend/pbt/tests/rest_timer.rs` に性質テストを置く。
