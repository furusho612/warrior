# トレーニングと種目のメモを実装する

- Requirements: REQ-REC-007
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-memos

## 目的

トレーニング全体と種目ごとにメモを残せるようにする。
保存したメモを、そのトレーニングと種目の表示で読み出せるようにする。
メモを AI の評価と提案の入力に含める。

## 優先度根拠

メモは、痛みやけがの記述に対する安全ガードと、種目ごとの次回セットの提案の入力になる。
メモの保存の場所を先に決めないと、AI に渡すメモと画面に出すメモが食い違う。

## 現状

0022 でトレーニング、0024 で種目、0025 から 0031 でセットを実装する。
しかし、トレーニング全体と種目ごとのメモの入力、保存、表示がない。

## 設計方針

メモは、トレーニングと種目に持たせる。
セットには持たせない。ADR-004 の判断に従う。

トレーニングのメモは、トレーニングの記録の画面とサマリーで入力できる。
種目のメモは、記録の種目の画面で入力できる。
メモは任意とし、空のままでも保存できる。
長さは 2000 文字以下とする。
改行を含むことができる。

メモは、端末内の保存と送信待ちの列を通る。
保存したメモは、トレーニングと種目の表示で読み出せる。
過去のトレーニングの編集でも、メモを編集できる。

メモは、0014 の AI のコンテキストに含める。
痛み、けが、体調不良の記述に対する安全ガードは、0014 の固定の一覧で判定する。
画面に表示するときは、HTML として解釈せず、テキストとして表示する。

メモの内容は、ログに出さない。

## 完了条件

- [ ] トレーニング全体と種目ごとにメモを入力して保存できる。保存したメモは、そのトレーニングと種目の表示で読み出せる。これは REQ-REC-007 の受入基準に対応する。
- [ ] メモが空でも保存できる。
- [ ] 2000 文字を超えるメモを拒否する。
- [ ] 改行を含むメモが保存され、表示される。
- [ ] メモがセットではなく、トレーニングと種目に保存される。
- [ ] メモが端末内の保存と送信待ちの列を通る。
- [ ] 過去のトレーニングの編集で、メモを編集できる。
- [ ] メモが 0014 の AI のコンテキストに含まれる。
- [ ] 画面に表示するときに、メモが HTML として解釈されず、テキストとして表示される。
- [ ] メモの内容がログに出ない。
- [ ] PBT で、任意の文字列のメモが保存と読み出しで往復し、2000 文字の境界で受理と拒否が分かれることを確かめる。
- [ ] 例示テストで、空のメモ、改行、絵文字を含まない日本語、2000 文字、2001 文字、HTML のタグを含む文字列を確かめる。
- [ ] E2E で、トレーニングと種目のメモを入力し、保存し、表示し、AI の入力に含まれることを確かめる。

## 解決方法

`migrations/` の `training_sessions` と `training_exercises` に `memo` を追加する。0021 の表に列を足す。
`backend/warrior_core/src/memo.rs` に、長さの検証と表示用の無害化を置く。
`backend/warrior/src/session.rs` と `backend/warrior/src/session_exercise.rs` にメモの保存を追加する。
`backend/warrior_core/src/ai/context.rs` にメモを含める処理を追加する。
`frontend/src/screens/record.rs` にメモの入力を置く。
`backend/warrior/tests/e2e_memo.rs` に E2E を追加する。
`backend/pbt/tests/memo.rs` に性質テストを置く。
