# Dioxus のアプリシェルと画面の経路を用意する

- Requirements: REQ-NFR-001, REQ-NFR-002, REQ-NFR-011
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/other-frontend-shell

## 目的

Dioxus のアプリに、画面の経路、共通のレイアウト、下部のタブ、日本語の文言の表、スマートフォンと PC の幅への対応を用意する。
後続の画面が同じ枠組みの上に実装できるようにする。

## 優先度根拠

すべての画面がこのシェルと経路の台帳に依存する。
経路と文言の置き場を先に決めないと、画面ごとに URL と文字列がばらける。

## 現状

0001 で最小の Dioxus アプリを作るが、画面の経路、共通のレイアウト、下部のタブ、文言の表、画面幅への対応がない。
そのため、後続の画面がそれぞれ独自のレイアウトと文字列を持つ状態になる。

## 設計方針

`dioxus-router` で画面の経路を扱い、経路の台帳を 1 か所に置く。
経路は次のとおりとする。

```text
/                       ホーム
/record                 記録中
/record/:session_id     記録中
/calendar               カレンダー
/library                種目ライブラリ
/library/:exercise_id   種目詳細
/analysis               分析
/routines               ルーティンとプログラム
/summary/:session_id    終了サマリー
/mypage                 マイページ
```

画面の外枠は、上部の 54px を端末の表示領域として空け、下部にタブを置く。
記録中の画面は下部のタブを隠し、左に幅 60px の種目レール、下にレストタイマーを固定する枠を用意する。
実際のレールとタイマーの中身は 0022 と 0034 で実装する。

基準の大きさは 390 × 844 とする。
スマートフォンの幅と PC の幅の両方で、横にはみ出さずに操作できるようにする。
押せる要素は 44px 以上、文字は 11px 以上にする。
角は丸めず、面の重なりは影ではなく色の差で示す。

UI の文言は、型付きのキーと日本語の表で持つ。
画面のコードに文字列を直接書かない。
i18n の汎用クレートは追加しない。

テーマの属性は 0005 の生成物を使い、初期値は端末の設定に合わせる。
手動の切り替えと保存は 0062 で実装する。

## 完了条件

- [ ] 経路の台帳のすべての経路を開くと、対応する画面の枠が表示される。これは PRD の要求 ID を持たないシェルの条件である。
- [ ] 下部のタブからホーム、カレンダー、種目ライブラリ、分析、マイページへ移動できる。
- [ ] 記録中の画面で下部のタブが隠れ、種目レールとレストタイマーの枠が表示される。
- [ ] スマートフォンの幅と PC の幅で、横スクロールが起きず、押せる要素と文字の最小値が守られる。これは REQ-NFR-002 の受入基準「画面が欠けずに操作できる」を満たす。
- [ ] 対象のブラウザの最新版で画面を操作できる。これは REQ-NFR-001 の受入基準を満たす。E2E のブラウザは 0008 の基盤で起動する。
- [ ] 画面に表示する文言がすべて日本語である。これは REQ-NFR-011 の受入基準を満たす。
- [ ] 画面のコードに文言のリテラル値と色のリテラル値がない。
- [ ] 経路の解析と文言のキーの参照を単体テストで確かめる。画面の表示と最小値は E2E で確かめる。
- [ ] 画面の部品は状態を持たないため、この issue では PBT の対象を置かない。

## 解決方法

`frontend/src/main.rs` に `dioxus-router` の `Router` を置く。
`frontend/src/routes.rs` に経路の台帳を置く。
`frontend/src/layout.rs` に共通の枠、下部のタブ、記録中の枠を置く。
`frontend/src/text.rs` に型付きのキーと日本語の表を置く。
`frontend/src/screens/` に 11 の画面の空の部品を置く。
`frontend/src/theme.rs` にテーマの属性を設定する関数を置く。
`frontend/tailwind.css` に 44px と 11px の最小値、角の丸めがないことを反映する。
`frontend/src/routes.rs` と `frontend/src/text.rs` の単体テストを `frontend/src/` の `#[cfg(test)]` に置く。
ブラウザの E2E は 0008 の基盤で `frontend/tests/` に置く。
