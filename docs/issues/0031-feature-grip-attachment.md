# グリップとアタッチメントの選択と比較を実装する

- Requirements: REQ-SET-011, REQ-LIB-011
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-grip-attachment

## 目的

グリップを選べる種目で、記録のときに握り方、手幅、アタッチメントを選べるようにする。
選んだグリップをセットとともに保存し、前回の記録と自己ベストを同じグリップと同じアタッチメントの記録に限る。
履歴とグラフをグリップとアタッチメントで絞り込めるようにする。

## 優先度根拠

グリップとアタッチメントは、前回の記録と自己ベストの比較のキーになる。
比較のキーを後から変えると、同じ種目の自己ベストが混ざり、分析の意味が変わる。

## 現状

0019 で種目ごとのグリップの選択肢を表せるようにし、0024 で前回の記録、0029 で自己ベストを実装する。
しかし、記録時のグリップの選択、セットへの保存、比較のキー、履歴とグラフの絞り込みがない。

## 設計方針

グリップの選択肢は、0019 の `GripMode` と `GripSelection` に従う。

- グリップを選ばない種目は、選択肢を表示しない。
- 握り方と手幅を選ぶ種目は、握り方 (順手、逆手、パラレル) と手幅 (ワイド、ミディアム、ナロー) を選ぶ。
- アタッチメントを選ぶ種目は、ワイドバー、ストレートバー、パラレルグリップ、マググリップ 7 種の合計 10 種から選ぶ。ワイドバーとストレートバーでは、順手か逆手かも選ぶ。

グリップとアタッチメントは、セットごとに保存する。
種目の既定の選択は、その種目の直近のセットの選択とする。
直近のセットがない場合は、種目の選択肢の最初の値とする。
利用者はセットごとに選択を変えられる。
同じ種目でも、グリップが違うセットを同じトレーニングに記録できる。

前回の記録と自己ベストは、同じ種目で、同じグリップと同じアタッチメントを選んだ記録だけを対象にする。
握り方と手幅を選ぶ種目では、握り方と手幅の両方が一致することを条件にする。
アタッチメントを選ぶ種目では、アタッチメントと、順手か逆手かの値が一致することを条件にする。
グリップを選ばない種目では、グリップの条件を付けない。

履歴とグラフは、グリップとアタッチメントの値で絞り込める。
絞り込みの条件は、種目が持つ選択肢のうち、値が指定されたものだけを適用する。
履歴とグラフの画面は 0049 が担う。この issue では、絞り込みのクエリと API を用意する。

セットのコピーと前回の表示は、グリップとアタッチメントもコピーする。

## 完了条件

- [ ] グリップを選べる種目で、記録のときに、種目に応じた握り方、手幅、アタッチメントを選べる。選んだグリップがセットとともに保存される。これは REQ-SET-011 の受入基準に対応する。
- [ ] 種目ごとの選択肢が、0019 の `GripMode` と `GripSelection` に従う。ワイドバーとストレートバーでは順手か逆手かを選べる。これは REQ-LIB-011 の受入基準に対応する。
- [ ] グリップを選ばない種目では、選択肢を表示せず、値も保存しない。
- [ ] 前回の記録と自己ベストが、同じグリップと同じアタッチメントの記録だけを対象にする。これは REQ-SET-011 の受入基準に対応する。
- [ ] 握り方と手幅の両方が一致することを、比較の条件にする。
- [ ] アタッチメントと順手か逆手かの両方が一致することを、比較の条件にする。
- [ ] 履歴とグラフをグリップとアタッチメントで絞り込めるクエリと API がある。画面は 0049 が担う。
- [ ] セットのコピーと前回の表示が、グリップとアタッチメントもコピーする。
- [ ] 種目の選択肢にない値を拒否する。
- [ ] PBT で、グリップとアタッチメントの比較のキーが、同じ値の組だけを一致させ、違う値の組を一致させないことを確かめる。
- [ ] 例示テストで、握り方 3 種と手幅 3 種、アタッチメント 10 種、ワイドバーとストレートバーの順手と逆手、グリップを選ばない種目を確かめる。
- [ ] E2E で、グリップを選び、前回の記録と自己ベストが同じグリップの記録に限られることを確かめる。

## 解決方法

`migrations/` の `sets` にグリップの選択の列を追加する。値は種別と、握り方、手幅、アタッチメント、順手か逆手かを持つ。
`backend/warrior_core/src/grip.rs` に、選択の型、選択肢の検証、比較のキーの作成を置く。
`backend/warrior/src/set.rs` にグリップの保存を追加する。
`backend/warrior/src/history.rs` に、グリップとアタッチメントの絞り込みのクエリを置く。
`frontend/src/screens/record.rs` にグリップの選択を置く。
`backend/warrior/tests/e2e_grip.rs` に E2E を追加する。
`backend/pbt/tests/grip.rs` に性質テストを置く。
