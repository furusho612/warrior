# 反動と補助の回数、RPE を実装する

- Requirements: REQ-SET-006, REQ-SET-007
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-reps-rpe

## 目的

セットごとに、反動を使った回数と補助を受けた回数を記録できるようにする。
セットごとに RPE を 6 から 10 まで 0.5 刻みで記録できるようにする。
反動と補助の回数を、総重量と推定 1RM の計算に 0012 の規則で反映する。

## 優先度根拠

反動と補助の回数は、ストリクト回数と推定 1RM を変える。
RPE は AI の評価と次回セットの提案の入力になる。
どちらも記録のデータの形に関わるため、セットの機能の中で先に固定する。

## 現状

0025 でセットの重量と回数、0026 でドロップセットの段、0027 で左右別とスーパーセットを実装する。
しかし、反動と補助の回数、RPE の入力と保存がない。

## 設計方針

反動の回数と補助の回数は、セットの段ごとに持つ。
入力は任意とし、空の場合は 0 とする。
反動の回数と補助の回数の合計が回数を超えるセットを拒否する。
ストリクト回数は、回数から反動の回数と補助の回数を引いた値とし、0 を下回る場合は 0 とする。
ストリクト回数は推定 1RM と自己ベストの種目別の総重量に使う。
総重量は、反動の回数を含め、補助の回数を含めない。

RPE はセットごとに持つ。
入力は任意とし、6.0 から 10.0 まで 0.5 刻みとする。
空のままでもセットを保存できる。
値は浮動小数の誤差を避けるため、10 倍した整数で保存する。
画面には 6.0 から 10.0 の表記で出す。
ドロップセットの行は RPE の欄を持たない。PRD のセットの要件より、デザインの「セット詳細の drawer」の規則を優先する。

反動と補助の回数、RPE は、端末内の保存と送信待ちの列を通る。
セットの詳細の drawer に表示する。
保存した値は、0049 の履歴にも表示する。

## 完了条件

- [ ] セットごとに、反動を使った回数と補助を受けた回数を入力して保存できる。保存した値はセットの詳細と履歴に表示される。これは REQ-SET-006 の受入基準に対応する。
- [ ] 反動の回数と補助の回数の合計が回数を超えるセットを拒否する。
- [ ] ストリクト回数が、回数から反動と補助の回数を引いた値になり、0 以上で回数以下になる。これは REQ-SET-006 の受入基準のうち、総重量と推定 1RM の計算の部分に対応する。
- [ ] 総重量の回数が、回数から補助の回数を引いた値になり、反動の回数を含む。推定 1RM と自己ベストの種目別の総重量がストリクト回数を使う。これは 0012 の計算で確かめる。
- [ ] セットごとに 6 から 10 まで 0.5 刻みで RPE を記録できる。RPE を空のままでもセットを保存できる。これは REQ-SET-007 の受入基準に対応する。
- [ ] 6.0 未満、10.0 を超える値、0.5 刻みでない値を拒否する。
- [ ] RPE が 10 倍した整数で保存され、画面に 6.0 から 10.0 の表記で出る。
- [ ] ドロップセットの行に RPE の欄がない。
- [ ] 反動と補助の回数、RPE が、端末内の保存と送信待ちの列を通る。
- [ ] PBT で、任意の回数と反動と補助の回数に対して、ストリクト回数が 0 以上で回数以下であり、0012 の計算と一致することを確かめる。
- [ ] 例示テストで、RPE の 6.0、6.5、10.0、空、5.5、10.5、0.25 刻みを確かめる。
- [ ] 例示テストで、反動と補助の合計が回数と等しい場合と超える場合を確かめる。
- [ ] E2E で、反動と補助の回数と RPE を入力し、保存と表示を確かめる。

## 解決方法

`migrations/` の `set_segments` に `momentum_reps` と `assisted_reps` を追加し、`sets` に `rpe_tenths` を追加する。
`backend/warrior_core/src/set_calc.rs` の `SetSegment` と `SetRecord` に値を追加する。
`backend/warrior_core/src/rpe.rs` に RPE の検証と表記を置く。
`backend/warrior/src/set.rs` に値の保存を追加する。
`frontend/src/screens/record.rs` のセット詳細の drawer に、反動と補助の回数、RPE の入力を置く。
`backend/warrior/tests/e2e_record_reps_rpe.rs` に E2E を追加する。
`backend/pbt/tests/reps_rpe.rs` に性質テストを置く。
