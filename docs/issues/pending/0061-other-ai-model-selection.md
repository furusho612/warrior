# Workers AI の無料枠から AI モデルを選定する

- Requirements: なし (ADR-018 のモデルの選定であり、PRD の要求 ID を持たない)
- Priority: Medium
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/other-ai-model-selection

## 目的

Workers AI の無料枠で動くモデルから、PRD のプロンプトに最も適したものを選ぶ。
日本語の品質、指示の遵守、出力の形式、安全の遵守、無料枠の消費を測り、`AI_MODEL` に固定する。

## 優先度根拠

AI の評価と提案の品質は、モデルの日本語の能力と指示の遵守に依存する。
無料枠を超えると生成が失敗するため、1 日あたりの Neurons の見積もりも選定の条件にする。

## 現状

0014 でプロンプトと出力の検証、0055 で Workers AI の呼び出し、0056 から 0060 で評価と提案を実装する。
しかし、`AI_MODEL` に固定するモデルが決まっておらず、無料枠の消費も見積もっていない。

## 設計方針

候補は、Workers AI の公式のモデルカタログと料金ページに載るテキスト生成モデルから選ぶ。
候補は、Cloudflare の「Your Data and Workers AI」の条件で、学習に使わないこととゼロデータ保持を確認する。
確認できないモデルは候補から外す。
無料枠は 1 日 10,000 Neurons で、毎日 00:00 UTC にリセットされる。
代表的なリクエストを入力 8,000 トークン、出力 1,200 トークンとし、1 日 20 回で 10,000 Neurons 以下になるモデルに限る。
この大きさは初期の目安であり、評価では実際の記録で測った最大の入力と出力を使う。
料金は公式の料金ページの Neurons の値を使い、入力と出力の合計で見積もる。

第一候補は `@cf/meta/llama-4-scout-17b-16e-instruct` とする。
131,000 トークンの文脈、関数呼び出し、ゼロデータ保持に対応し、ADR-018 の候補でもある。
代替候補は `@cf/openai/gpt-oss-20b`、`@cf/google/gemma-3-12b-it`、`@cf/meta/llama-3.3-70b-instruct-fp8-fast`、`@cf/deepseek-ai/deepseek-v4.1-flash-1017` とする。
`@cf/qwen/qwen3-30b-a3b-fp8` は 2026-11-20 に廃止予定のため、候補から外す。

評価は、PRD の付録のプロンプトと代表的な記録で行う。
記録は、目的 5 つ、レベル 3 つ、評価の日、週、月、次回セットの提案、メニューの最適化、目標重量の達成が難しい場合、痛みの記述がある場合を含む。
評価の観点は、日本語の自然さ、根拠の数値の正しさ、出力の形式の遵守、安全の指示の遵守、応答の時間、1 リクエストあたりの Neurons とする。

安全の指示の遵守では、痛み、けが、体調不良の記述がある場合に、負荷を増やす提案をしないことを確かめる。
出力の形式の遵守では、0014 の検証を通るかを確かめる。

第一候補が合格したら、そのモデルを `wrangler.toml` の production の `AI_MODEL` に固定する。
第一候補が合格しない場合は、代替候補のうち、無料枠の条件を満たす中で最も品質の高いモデルを選ぶ。
全ての候補が品質の基準を満たさない場合は、無料枠の条件を満たす中で最も品質の高いモデルを選び、制約を ADR-018 に記録する。
外部の AI サービスは使わない。ADR-018 は外部の提供者へのフォールバックを含まない。

staging を追加したときは、production と同じモデルを staging の `AI_MODEL` に置く。
モデルを変えるときは、同じ評価を行い、ADR に記録する。

## 完了条件

- [ ] 候補が Workers AI の公式のモデルカタログと料金ページに載っている。
- [ ] 候補が Cloudflare のデータ使用の条件で、学習に使わないこととゼロデータ保持を確認できる。
- [ ] 無料枠が 1 日 10,000 Neurons であり、毎日 00:00 UTC にリセットされることを、公式の料金ページで確かめる。
- [ ] 入力 8,000 トークン、出力 1,200 トークンのリクエストを 1 日 20 回実行しても、10,000 Neurons 以下になるモデルだけを候補にする。
- [ ] 第一候補が `@cf/meta/llama-4-scout-17b-16e-instruct` であり、代替候補が `@cf/openai/gpt-oss-20b`、`@cf/google/gemma-3-12b-it`、`@cf/meta/llama-3.3-70b-instruct-fp8-fast`、`@cf/deepseek-ai/deepseek-v4.1-flash-1017` である。
- [ ] `@cf/qwen/qwen3-30b-a3b-fp8` を、2026-11-20 の廃止予定を理由に候補から外す。
- [ ] 評価の観点が、日本語の自然さ、根拠の数値の正しさ、出力の形式の遵守、安全の指示の遵守、応答の時間、1 リクエストあたりの Neurons を含む。
- [ ] 痛み、けが、体調不良の記述がある場合に、負荷を増やす提案をしないことを確かめる。
- [ ] 出力が 0014 の検証を通ることを確かめる。
- [ ] 選んだモデルを `wrangler.toml` の production の `AI_MODEL` に固定する。
- [ ] staging を追加したときは、production と同じモデルを staging の `AI_MODEL` に置く。
- [ ] 評価の結果と選定の理由を issue に記録し、モデルの変更を ADR に記録する。
- [ ] 外部の AI サービスを使わない。

## 解決方法

`mise.toml` に、代表的な記録を入れてモデルを評価するタスクを追加する。
評価は Workers AI の Playground または staging で利用者が行い、結果を issue に記録する。
`wrangler.toml` の `[env.production]` の vars の `AI_MODEL` を、選んだモデルに更新する。
staging を追加したときは、`[env.staging]` の `AI_MODEL` にも同じ値を置く。
モデルの変更は ADR-018 に記録する。

## 止める理由

production のみを先に用意するため、staging がまだない。
代表的な記録の準備と、無料枠の範囲で評価を実行することが利用者に依存する。
エージェントは実環境へ接続しない。

## 再開条件

利用者が 0067 で staging を追加するか、Workers AI の Playground で評価できる状態を用意する。
利用者が代表的な記録と、評価の観点の重みを用意する。
