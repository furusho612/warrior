# カレンダーの月表示と部位の色分けを実装する

- Requirements: REQ-CLD-001, REQ-CLD-002, REQ-CLD-003, REQ-CLD-004, REQ-CLD-005, REQ-CLD-006
- Priority: Medium
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-calendar

## 目的

月表示のカレンダーで、トレーニングした日と部位を色で示し、その月のトレーニング日数と部位ごとの日数を表示する。
日付を選ぶと、その日の種目、セットの内容、総重量を表示する。
部位で絞り込むと、その部位を行った日だけを強調する。

## 優先度根拠

カレンダーは段階 2 の振り返りの入口であり、記録の日付と部位の色分けを使う。
日付の境界と部位の判定を先に固定しないと、日をまたぐ記録と複数の部位の扱いが変わる。

## 現状

0011 で日本時間の日付と月の境界、0019 で種目の部位区分、0021 から 0033 で記録を実装する。
しかし、カレンダーの表示、部位の色分け、日数の集計、日の詳細、絞り込み、凡例がない。

## 設計方針

カレンダーは月表示とし、前後の月へ移動できる。
表示する月の境界は、日本時間の 1 日 0 時から翌月 1 日 0 時の直前とする。
トレーニングの日付は、0011 の `JstDate` を使う。

トレーニングした日には、その日に行った部位区分の色を表示する。
複数の部位を行った日は、部位ごとの色を並べて表示する。
部位の色は、0005 の生成した部位の色を使う。
色分けの部位区分は、胸、背中、肩、二頭・前腕、三頭、脚、腹筋、その他の 8 つとする。
その日の部位は、記録した種目のスナップショットの部位区分から判定する。ADR-006 に従い、現在の種目マスターの区分ではなく、記録時の区分を使う。

その月のトレーニング日数と、部位区分ごとの日数を表示する。
部位区分ごとの日数は、その部位を行った日数とする。
1 日に複数の部位を行うと、部位区分ごとの日数の合計はトレーニング日数を超える。

日付を選ぶと、その日のトレーニングの種目、セットごとの内容、総重量を表示する。
セットの内容は、重量、回数または時間、セット種別、グリップとアタッチメント、RPE、反動と補助の回数とする。
総重量は 0012 の計算を使う。

部位を選んで絞り込むと、その部位を行った日だけを強調し、ほかの日を強調しない。
絞り込みは表示の強調だけを変え、日数を変えない。

凡例に、8 つの部位区分とそれぞれの色の対応を表示する。
ライトとダークの両方で、部位を判別できる色にする。

集計はサーバーで行い、画面は結果を表示する。ADR-016 の「グラフはフロントエンドで描画し、集計はバックエンドの API が行う」に従う。

## 完了条件

- [ ] 月表示のカレンダーに、トレーニングした日が表示される。前の月と次の月に移動すると、表示中の月がその月に切り替わる。これは REQ-CLD-001 の受入基準に対応する。
- [ ] トレーニングした日に、その日に行った部位区分の色が表示される。複数の部位を行った日は、部位ごとの色が並んで表示される。これは REQ-CLD-002 の受入基準に対応する。
- [ ] 表示中の月のトレーニング日数が表示される。部位区分ごとの日数も表示される。部位区分ごとの日数は、その部位を行った日数であり、1 日に複数の部位を行うと合計はトレーニング日数を超える。これは REQ-CLD-003 の受入基準に対応する。
- [ ] 日付を選ぶと、その日のトレーニングの種目、セットごとの内容、総重量が表示される。これは REQ-CLD-004 の受入基準に対応する。
- [ ] 部位を選んで絞り込むと、その部位を行った日だけが強調され、ほかの日は強調されない。これは REQ-CLD-005 の受入基準に対応する。
- [ ] カレンダーに、8 つの部位区分とそれぞれの色の対応が凡例として表示される。これは REQ-CLD-006 の受入基準に対応する。
- [ ] その日の部位が、記録時の種目のスナップショットの部位区分から判定される。
- [ ] 月の境界が日本時間で決まり、端末のタイムゾーンに依存しない。
- [ ] ライトとダークの両方で、部位の色を判別できる。
- [ ] 絞り込みが、日数の集計を変えず、強調だけを変える。
- [ ] PBT で、トレーニング日数と部位区分ごとの日数が、その月の記録から正しく集計されることを確かめる。
- [ ] PBT で、1 日に複数の部位を行うと、部位区分ごとの日数の合計がトレーニング日数を超えることを確かめる。
- [ ] 例示テストで、月の境界、閏年、複数の部位の日、絞り込み、空の月を確かめる。
- [ ] E2E で、月を移動し、日を選び、部位で絞り込み、凡例を確かめる。

## 解決方法

`backend/warrior_core/src/calendar.rs` に、日ごとの部位の判定と、月のトレーニング日数と部位区分ごとの日数の集計を置く。
`backend/warrior/src/calendar.rs` に、月の取得と日の詳細を置く。
`backend/warrior/src/router.rs` に `GET /api/calendar`、`GET /api/calendar/:date` を追加する。
`frontend/src/screens/calendar.rs` に月表示、色分け、日数の集計、日の詳細、絞り込み、凡例を置く。
`frontend/src/text.rs` に部位区分と凡例の文言を追加する。
`backend/warrior/tests/e2e_calendar.rs` に E2E を追加する。
`backend/pbt/tests/calendar.rs` に性質テストを置く。
