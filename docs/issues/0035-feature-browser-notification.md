# ブラウザ通知でレストの終了を知らせる

- Requirements: REQ-TMR-007, REQ-NFR-008
- Priority: Medium
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-browser-notification

## 目的

ブラウザ通知を許可している場合、別のタブを表示中でもレストの終了を通知する。
通知を許可しない場合でも、レストタイマーが音と画面表示で動作するようにする。

## 優先度根拠

ブラウザ通知は段階 4 の機能であり、レストタイマーの音と画面表示が先に動く必要がある。
通知の許可の取得を画面の読み込み時に行うと、利用者の意図しない許可の要求になる。

## 現状

0034 でレストタイマー、残り時間、終了の音と画面表示を実装する。
しかし、ブラウザ通知の許可の取得、別のタブを表示中の通知、通知を押したときの画面の移動がない。

## 設計方針

ブラウザ通知は、利用者が設定の画面で有効にしたときにだけ許可を求める。
画面の読み込み時に許可を求めない。
許可の状態は `Notification.permission` で確認し、`default`、`granted`、`denied` を扱う。

レストの終了予定時刻になったとき、画面が隠れている場合はブラウザ通知を出す。
画面が見えている場合は、画面の終了の表示だけを出す。
通知は Service Worker の登録から `showNotification` を呼ぶ。
Service Worker が使えない場合は、ページの `Notification` を使う。

通知の本文には、種目名、重量、回数などの記録の内容を含めない。
レストが終了したことだけを伝える。
通知を押したときは、アプリの画面を開くか、既に開いている画面にフォーカスする。

通知を許可しない場合、または通知の API が使えない場合も、レストタイマーは音と画面表示で動作する。
通知の失敗を理由に、タイマーの終了の処理を止めない。

バックグラウンドのタブでは、ブラウザがタイマーの処理を遅らせる場合がある。
通知は、終了予定時刻を過ぎた後の最初の再描画で出す。
遅れた通知の時刻を、終了予定時刻として扱わない。

プッシュ通知は 0036 と 0037 が担う。
この issue は、画面が生きている間のブラウザ通知を扱う。

## 完了条件

- [ ] ブラウザ通知を許可した状態で別のタブを表示しているとき、レストの終了がブラウザ通知で届く。これは REQ-TMR-007 の受入基準に対応する。
- [ ] ブラウザ通知を許可しない状態でも、レストタイマーが音と画面表示で動作する。許可した場合だけ、ブラウザ通知が届く。これは REQ-NFR-008 の受入基準に対応する。
- [ ] 通知の許可を、利用者が設定で有効にしたときにだけ求める。画面の読み込み時に求めない。
- [ ] 通知の本文に、種目名、重量、回数などの記録の内容が含まれない。
- [ ] 通知を押すと、アプリの画面が開くか、既に開いている画面にフォーカスする。
- [ ] 通知の API が使えない場合も、タイマーの終了の処理が止まらない。
- [ ] 通知が遅れた場合も、終了予定時刻を通知の時刻で上書きしない。
- [ ] ブラウザのテストで、許可、拒否、未定の 3 つの状態と、通知の表示、通知を押したときの画面の移動を確かめる。
- [ ] ブラウザのテストで、通知を拒否した状態でもタイマーが音と画面表示で終了することを確かめる。
- [ ] E2E で、2 つのタブを開き、片方でタイマーを動かし、もう片方を表示しているときに通知が届くことを確かめる。
- [ ] 通知の内容と表示の条件を純粋な関数に分け、単体テストで確かめる。PBT は、表示の条件が画面の表示状態だけで決まることを確かめる。

## 解決方法

`frontend/src/notification.rs` に、許可の状態、通知の表示、押したときの画面の移動を置く。
`frontend/src/screens/record.rs` のタイマーの終了の処理から通知を呼ぶ。
`frontend/src/screens/mypage.rs` に、通知を有効にする設定を置く。設定の保存は 0062 が担う。
`frontend/src/text.rs` に通知の文言を追加する。
`frontend/tests/notification.rs` にブラウザのテストを追加する。
`backend/warrior/tests/e2e_notification.rs` に E2E を追加する。
`backend/pbt/tests/notification.rs` に表示の条件の性質テストを置く。
