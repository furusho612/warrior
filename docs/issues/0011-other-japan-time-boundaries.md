# 日本時間の日付と週、月の境界を実装する

- Requirements: なし (ADR-005 の共通基盤であり、各機能の要求は利用側の issue が実装する)
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/other-japan-time-boundaries

## 目的

UTC で保存した時刻から、日本時間の日付、週、月の境界を一意に決める純粋なロジックを作る。
カレンダー、分析、AI の評価期間、トレーニングの日付が同じ境界を使えるようにする。

## 優先度根拠

カレンダー、部位別の分析、AI の評価のすべてがこの境界に依存する。
端末のタイムゾーンによって集計が変わると、同じ記録の日付と件数が画面ごとに食い違う。

## 現状

ADR-005 は日本時間の日付と境界を決めているが、実装がない。
日付の計算を各機能が個別に行うと、週の始まりと月の境界の扱いがばらける。

## 設計方針

`backend/warrior_core/src/jst.rs` に、日本時間の日付と境界の型と関数を置く。
`chrono` と `time` は ADR-025 で追加しないため、UTC の ISO 8601 の固定長の文字列を自前で解析する。

型は次のとおりとする。

- `UtcInstant`: UTC の秒とナノ秒を持つ。保存は ISO 8601 の文字列で行う。
- `JstDate`: 日本時間の年、月、日を持つ。保存は `YYYY-MM-DD` の文字列で行う。
- `JstWeek`: 月曜 0 時に始まり、次の月曜 0 時の直前で終わる範囲を持つ。
- `JstMonth`: 1 日 0 時に始まり、翌月 1 日 0 時の直前で終わる範囲を持つ。

日本時間は UTC に 9 時間を足した時刻とする。
日本は夏時間を採用していないため、夏時間の切り替えを扱わない。

関数は次のとおりとする。

- UTC の ISO 8601 の文字列を `UtcInstant` に変換する。
- `UtcInstant` を日本時間の `JstDate` に変換する。
- `JstDate` を `YYYY-MM-DD` に整形し、`YYYY-MM-DD` から復元する。
- `JstDate` から、その日を含む週の開始日と終了日、月の開始日と終了日を返す。
- 週の開始は月曜とし、日曜はその週の最終日とする。
- 月の境界と閏年を正しく扱う。

日付の計算は純粋な関数に閉じる。
現在時刻は呼び出し側から渡す。
テストのために現在時刻を固定できない実装を残さない。

## 完了条件

- [ ] 任意の UTC の時刻から日本時間の日付が一意に決まる。同じ時刻からは常に同じ日付になる。これは PRD の要求 ID を持たない基盤の条件である。
- [ ] `YYYY-MM-DD` の整形と復元が往復し、存在しない日付と形式の違う文字列を拒否する。
- [ ] 週が月曜 0 時に始まり、次の月曜 0 時の直前で終わる。日曜 23:59:59 と月曜 0:00 の境界で週が切り替わる。
- [ ] 月が 1 日 0 時に始まり、翌月 1 日 0 時の直前で終わる。月末と閏年の 2 月 29 日を正しく扱う。
- [ ] 日本時間の日付が、UTC の日付と異なる時刻の例で正しく変換される。例: UTC の 2026-11-11 15:00 は日本時間の 2026-11-12 である。
- [ ] 端末のタイムゾーンを変えても、同じ UTC の時刻から同じ日本時間の日付が出る。
- [ ] PBT で、任意の UTC の時刻に対する日付の一意性、`YYYY-MM-DD` の往復、週の開始が月曜であること、月の境界と閏年を確かめる。
- [ ] 例示テストで、日曜 23:59:59 と月曜 0:00、月末、閏年の境界を確かめる。
- [ ] `chrono`、`time`、その他の日付のクレートを追加しない。

## 解決方法

`backend/warrior_core/src/jst.rs` に型と関数を置く。
`backend/warrior_core/src/lib.rs` から `pub mod jst;` で公開する。
`backend/pbt/tests/jst.rs` に、上の性質のテストを置く。
`backend/warrior_core/src/jst.rs` の `#[cfg(test)]` に境界の例示テストを置く。
`backend/warrior/tests/` の D1 の結合テストで、`YYYY-MM-DD` の文字列がそのまま保存され、読み出されることを確かめる。
