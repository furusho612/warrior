# 部位ごとの回復状況を実装する

- Requirements: REQ-ANL-008, REQ-ANL-009, REQ-ANL-010
- Priority: Medium
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-recovery-status

## 目的

部位ごとに、最後にトレーニングしてからの経過時間をもとに、回復中の 3 段階の状態を表示する。
回復の目安時間を部位区分ごとの既定値とし、その他を除く全ての部位を 48 時間から 72 時間とする。
回復状況が目安であることを注記する。

## 優先度根拠

回復状況は段階 2 の分析とホームの輪に表示され、AI の次回セットの提案の入力になる。
目安時間の境界を先に固定しないと、画面と AI で回復の判断が食い違う。

## 現状

0011 で日本時間の時刻、0019 で種目の部位区分、0021 から 0033 で記録を実装する。
しかし、部位ごとの最後のトレーニングの取得、回復の 3 段階の判定、注記、ホームの輪への反映がない。

## 設計方針

部位ごとに、最後にトレーニングした時刻を求める。
最後のトレーニングの時刻は、終了の時刻がある場合はその時刻とし、日付だけの記録の場合は、その日の翌日の 0 時 (日本時間) とする。
日付だけの記録の時刻を翌日の 0 時とするのは、回復を早く見積もらないためである。

経過時間は、表示の時点の時刻から最後のトレーニングの時刻を引いた値とする。最後のトレーニングの時刻は、PRD の「計算ルールと用語定義」の最後のトレーニング時刻に従う。
状態は、回復中、ほぼ回復、回復済みの 3 段階とする。
目安時間の下限は 48 時間、上限は 72 時間とする。
経過時間が下限未満の場合は回復中、下限以上上限未満の場合はほぼ回復、上限以上の場合は回復済みとする。

目安時間は部位区分ごとの既定値とし、その他を除く全ての部位で 48 時間から 72 時間とする。
個人差やトレーニング量による補正は行わない。
部位区分がその他の種目は、回復状況の対象にしない。

最後のトレーニングがない部位は、回復状況の値を持たず、記録がないことを表示する。
回復状況の近くに、目安であり体調に応じて判断するよう求める注記を表示する。

ホームの輪は 0047 が表示し、この issue の値を 8 つの部位区分のうち、その他を除く 7 つに表示する。

回復状況は、表示の時点の時刻で計算する。
現在時刻は呼び出し側から渡し、テストのために固定できるようにする。

## 完了条件

- [ ] 部位ごとに、最後にトレーニングしてからの経過時間に応じて、回復中、ほぼ回復、回復済みの 3 段階のいずれかが表示される。目安時間の下限未満は回復中、下限以上上限未満はほぼ回復、上限以上は回復済みとなる。部位区分がその他は回復状況に含めない。これは REQ-ANL-008 の受入基準に対応する。
- [ ] 回復の目安時間に部位区分ごとの既定値を使い、その他を除く全ての部位で 48 時間から 72 時間とする。トレーニング量と個人差による補正を加えない。これは REQ-ANL-009 の受入基準に対応する。
- [ ] 回復状況の近くに、目安であり体調に応じて判断するよう求める注記が表示される。これは REQ-ANL-010 の受入基準に対応する。
- [ ] ホームの輪に、その他を除く 7 つの部位の回復状況が表示される。
- [ ] 最後のトレーニングがない部位に、記録がないことを表示する。
- [ ] 日付だけの記録の最後のトレーニングの時刻が、その日の翌日の 0 時 (日本時間) になる。
- [ ] 経過時間が 48 時間と 72 時間の境界で、状態が切り替わる。
- [ ] PBT で、任意の最後のトレーニングの時刻と現在時刻に対して、状態が経過時間と 48 時間と 72 時間の境界から一意に決まることを確かめる。
- [ ] 例示テストで、47.9 時間、48 時間、71.9 時間、72 時間、最後のトレーニングがない部位、日付だけの記録、その他の部位を確かめる。
- [ ] E2E で、分析の画面とホームの輪に回復状況が表示され、注記が出ることを確かめる。

## 解決方法

`backend/warrior_core/src/recovery.rs` に、最後のトレーニングの時刻、経過時間、3 段階の判定を置く。
`backend/warrior/src/recovery.rs` に、部位ごとの最後のトレーニングの取得を置く。
`backend/warrior/src/router.rs` に `GET /api/analysis/recovery` を追加する。
`frontend/src/screens/analysis.rs` に回復状況と注記を置く。
`frontend/src/screens/home.rs` の輪に回復状況を渡す。
`frontend/src/text.rs` に 3 段階と注記の文言を追加する。
`backend/warrior/tests/e2e_recovery.rs` に E2E を追加する。
`backend/pbt/tests/recovery.rs` に性質テストを置く。
