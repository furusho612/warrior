# 推定 1RM の表示と自己ベストの判定を実装する

- Requirements: REQ-SET-008, REQ-SET-009
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-one-rm-personal-best

## 目的

重量と回数を入力したときに、そのセットの推定 1RM を表示する。
セットを完了した時点で自己ベストの更新を判定し、更新したものをその場で表示する。
自己ベストの対象は、最大重量、推定 1RM、種目別の総重量、時間の種目の最長時間とする。

## 優先度根拠

推定 1RM と自己ベストは、記録中の達成感と、分析と AI の評価の基礎になる。
判定の規則を先に固定しないと、記録、サマリー、分析で自己ベストが食い違う。

## 現状

0012 で推定 1RM、総重量、自己ベストの対象の計算を実装する。
0025 から 0028 でセットの入力、ドロップセット、左右別、反動と補助、RPE を実装する。
しかし、入力中の推定 1RM の表示、セット完了時の自己ベストの判定、保存、その場の表示がない。

## 設計方針

推定 1RM は、重量とストリクト回数から 0012 の式で求める。
回数が 1 のときは重量と同じ値とする。
回数が 0 のときは表示しない。
回数が 10 を超えるセットは、参考値の印を付けて表示する。
時間で記録する種目では、推定 1RM を表示しない。

自己ベストは、利用者、種目、グリップとアタッチメントの組、種類ごとに 1 つの値を持つ。
種類は、最大重量、推定 1RM、種目別の総重量、最長時間とする。
値と達成日、達成したトレーニングの ID を保存する。

セットを完了した時点で、次の候補を作り、保存済みの自己ベストと比べる。

- 最大重量は、ドロップセットの最初の段の重量とする。
- 推定 1RM は、ドロップセットの最初の段の重量とストリクト回数から求める。
- 種目別の総重量は、今回のトレーニングのその種目の全セットの総重量を、ストリクト回数で計算する。
- 最長時間は、時間で記録する種目のセットの時間とする。

ウォームアップセットは、自己ベストの対象にしない。
グリップとアタッチメントが違う記録は、別の自己ベストとして比べる。
グリップとアタッチメントの分離は、0031 の完了後に確かめる。
0031 より先に着手する場合は、グリップを持たない種目だけで判定を実装し、0031 で分離を追加する。
同じトレーニングの中で同じ種類の自己ベストを複数回更新した場合は、最後の値を残す。

更新した自己ベストは、セットの完了の直後に画面に表示する。
サマリーの「更新した自己ベスト」は、そのトレーニングで更新した自己ベストの一覧とする。

過去の記録の編集と削除で自己ベストが変わる場合は、0032 が対象の種目の自己ベストを全ての記録から計算し直す。

## 完了条件

- [ ] 重量と回数を入力すると、そのセットの推定 1RM が 0012 の式の値として表示される。回数が 1 のときは重量と同じ値が表示される。これは REQ-SET-008 の受入基準に対応する。
- [ ] 回数が 0 のときは推定 1RM を表示せず、回数が 10 を超えるときは参考値の印を付ける。
- [ ] 時間で記録する種目では推定 1RM を表示しない。
- [ ] セットを完了した時点で、最大重量、推定 1RM、種目別の総重量、時間の種目の最長時間の自己ベストを判定し、更新したものをその場で表示する。これは REQ-SET-009 の受入基準に対応する。
- [ ] 最大重量と推定 1RM がドロップセットの最初の段だけを対象にし、種目別の総重量がドロップセットの全段を対象にする。これは REQ-SET-009 の受入基準に対応する。
- [ ] ウォームアップセットが自己ベストの対象にならない。
- [ ] グリップとアタッチメントが違う記録が、別の自己ベストとして比べられる。0031 の完了後に確かめる。
- [ ] 同じトレーニングで同じ種類の自己ベストを複数回更新した場合、最後の値が残る。
- [ ] サマリーの「更新した自己ベスト」が、そのトレーニングで更新した自己ベストの一覧と一致する。
- [ ] 自己ベストの表が、利用者、種目、グリップとアタッチメント、種類ごとに 1 行を持つ。
- [ ] PBT で、自己ベストの判定が、全ての記録から計算し直した値と一致することを確かめる。
- [ ] 例示テストで、最大重量、推定 1RM、種目別の総重量、最長時間の 4 種類と、ドロップセット、ウォームアップ、グリップの分離を確かめる。
- [ ] 結合テストで、セットの完了の応答に更新した自己ベストが含まれることを確かめる。
- [ ] E2E で、自己ベストを更新し、その場の表示とサマリーの一覧を確かめる。

## 解決方法

`migrations/` に `personal_bests` の表を追加する。
`backend/warrior_core/src/personal_best.rs` に、候補の作成と比較、更新した自己ベストの判定を置く。
`backend/warrior/src/set.rs` のセットの完了の処理に自己ベストの判定を加える。
`backend/warrior/src/personal_best.rs` に D1 の読み書きを置く。
`frontend/src/screens/record.rs` に推定 1RM の表示と自己ベストの更新の表示を置く。
`frontend/src/screens/summary.rs` に更新した自己ベストの一覧を置く。
`backend/warrior/tests/e2e_personal_best.rs` に E2E を追加する。
`backend/pbt/tests/personal_best.rs` に性質テストを置く。
`backend/warrior_core/src/account_deletion.rs` の表の一覧に `personal_bests` を追加する。
