# 独自種目の追加とマスターの種目の編集、初期化を実装する

- Requirements: REQ-LIB-005, REQ-LIB-009, REQ-LIB-013
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-custom-exercise-override

## 目的

利用者が独自の種目を追加、編集、削除できるようにする。
マスターの種目も利用者が編集、削除でき、初期の内容に戻せるようにする。
記録に使われている種目を編集、削除しても、過去の記録を変えない。

## 優先度根拠

独自種目とマスターの編集は、種目ライブラリの利用の幅を決める。
過去の記録のスナップショットとの分離を先に固定しないと、種目の編集が過去の記録を書き換える。

## 現状

0019 で種目マスター、独自種目、利用者ごとの上書きの表と型を実装する。
0024 で記録の種目にスナップショットを保存する。
しかし、独自種目の追加、編集、削除、マスターの種目の編集、削除、初期化の経路がない。

## 設計方針

独自種目の追加では、名称、部位区分、記録方式を必須とする。
任意の項目は、使用器具、主働筋と補助筋、やり方、注意点、コツ、左右別の可否、グリップの選択肢とする。
追加した独自種目は、種目ライブラリの一覧に現れる。
追加した独自種目を編集でき、削除すると一覧から消える。

マスターの種目の編集と削除は、利用者ごとの上書きとして保存する。
上書きは、編集した項目だけを持つ。
削除は、削除の印を持つ。
初期の内容に戻す操作は、その利用者の上書きを削除する。
一覧と詳細は、マスターの値に上書きを適用した内容を表示する。

記録に使われている種目を編集しても、過去の記録に表示される種目名、部位区分、重量と回数は変わらない。
過去の記録は、0024 で保存したスナップショットを使う。
種目を削除しても、その種目を使った過去の記録は残り、開いて読める。
マスターの種目と独自種目を同じ扱いとする。

削除した種目の ID は再利用しない。
新しい種目に同じ ID を割り当てると、過去の記録が別の種目の履歴に混ざるためである。

お気に入りと履歴とグラフは、上書きを適用した種目の ID を使う。
種目の ID は編集で変えない。

## 完了条件

- [ ] 独自の種目を追加すると、種目ライブラリの一覧に現れる。名称、部位区分、記録方式のいずれかが空のままでは保存できない。追加した種目を編集でき、削除すると一覧から消える。これは REQ-LIB-005 の受入基準に対応する。
- [ ] 記録に使われている種目を編集しても、過去の記録に表示される種目名、部位区分、重量と回数は変わらない。種目を削除しても、その種目を使った過去の記録は残り、開いて読める。これは REQ-LIB-009 の受入基準に対応する。
- [ ] マスターの種目を編集すると、一覧と詳細に編集後の内容が表示され、削除すると一覧から消える。編集したマスターの種目を初期の内容に戻すと、表示がマスターの元の内容に戻る。これは REQ-LIB-013 の受入基準に対応する。
- [ ] 上書きが、利用者ごとに分かれ、別の利用者の表示に影響しない。
- [ ] 初期化の操作で、その利用者の上書きだけが削除され、マスターの行は変わらない。
- [ ] 削除した種目の ID を、新しい種目に割り当てない。
- [ ] 独自種目の追加と編集と削除、マスターの編集と削除と初期化が、端末内の保存と送信待ちの列を通る。
- [ ] 過去の記録のスナップショットが、種目の編集と削除の後に変わらない。
- [ ] PBT で、マスターの値に上書きを適用した結果が、編集した項目だけを置き換え、ほかの項目をマスターの値のままにすることを確かめる。
- [ ] PBT で、種目の編集と削除の後に、過去の記録のスナップショットが変わらないことを確かめる。
- [ ] 例示テストで、必須項目の欠落、独自種目の編集と削除、マスターの編集と削除と初期化、別の利用者の分離を確かめる。
- [ ] E2E で、独自種目を追加し、記録に使い、種目を編集し、過去の記録が変わらないことを確かめる。

## 解決方法

`backend/warrior_core/src/exercise_override.rs` に、上書きの適用と初期化の関数を置く。
`backend/warrior/src/custom_exercise.rs` に、独自種目の追加、編集、削除を置く。
`backend/warrior/src/exercise_override.rs` に、マスターの編集、削除、初期化を置く。
`backend/warrior/src/router.rs` に独自種目と上書きの経路を追加する。
`frontend/src/screens/library.rs` に追加、編集、削除、初期化の操作を置く。
`frontend/src/screens/exercise.rs` に編集の入口を置く。
`backend/warrior/tests/e2e_exercise_edit.rs` に E2E を追加する。
`backend/pbt/tests/exercise_override.rs` に性質テストを置く。
