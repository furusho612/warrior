# D1 のマイグレーションと SQL の組み立ての基盤を用意する

- Requirements: なし (データベース基盤は ADR-015 の判断であり、PRD の要求 ID を持たない)
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/other-database-foundation

## 目的

D1 のスキーマをマイグレーションで管理し、プレースホルダ付きの SQL を純粋なロジックで組み立てる基盤を作る。
利用者ごとの行とマスターの行を分ける規則を、後続の issue が同じ形で実装できるようにする。

## 優先度根拠

認証、記録、種目、ルーティン、AI の保存がすべてこの基盤に依存する。
SQL の組み立てと ID の検証を先に固定しないと、テーブルごとに作法がばらける。

## 現状

`wrangler.toml` は 0002 で用意するが、マイグレーションのディレクトリ、SQL の組み立てのクレート、D1 の結合テストの補助がない。
ID の形式、時刻の保存形式、利用者 ID の条件の付け方も決まっていない。

## 設計方針

スキーマの変更は `wrangler` の D1 マイグレーションで管理し、SQL ファイルを `migrations/` に置く。
デプロイの前に、対象の環境へマイグレーションを適用する。

SQL は ORM を使わず、プレースホルダ付きの SQL を直接渡す。
SQL の組み立ては `backend/warrior_core` に置き、D1 への実行は `backend/warrior` に置く。
この分離により、SQL の組み立てをネイティブのテストで検証できる。

利用者自身の行は `users` に置き、利用者 ID の列を持たない。
利用者に属するテーブルは `user_id` の列を持ち、すべてのクエリで `user_id` を条件に含める。
利用者に属さないマスターのテーブルは `user_id` を持たない。
利用者 ID を持たない行は、マスターの種目、プログラム、プログラムの日、筋肉の単位、ログインのチャレンジ、Google OAuth の状態、IP ごとのレート制限のカウンタである。
マスターの種目と独自種目は別の表に置く。
マスターの種目の編集と削除は、利用者ごとの上書きの表に保存する。

主キーは UUID v4 の文字列とする。
記録中のトレーニング、トレーニングの種目、セット、ドロップセットの段、スーパーセットの組は、アプリが生成した UUID v4 を使う。
マスターの種目、プログラム、ライブラリで作る独自種目、その他の行は、サーバーが生成した UUID v4 を使う。
サーバーは ID の形式と所有権を検証して保存する。
時刻は ISO 8601 の UTC の文字列で保存する。
トレーニングの日付は、日本時間で決めた `YYYY-MM-DD` の文字列で保存する。
複数の文をまとめて書き込むときは `batch()` を使う。
一覧のページングはカーソル方式とする。

`backend/warrior_core` に次の純粋な関数を置く。

- UUID v4 の形式を検証する関数
- カーソルの値を符号化し、復号する関数
- プレースホルダ付きの SQL と、そのバインド値の組を組み立てる型
- 利用者に属するクエリに `user_id` の条件を必ず含めることを型で表す仕組み

時刻と乱数は、純粋なロジックの外から注入する。
テストのために現在時刻を固定できない実装を残さない。

## 完了条件

- [ ] `mise run db-migrate-local` がローカルの D1 に `migrations/` の SQL を順に適用する。
- [ ] UUID v4 の形式の検証が、正しい形式を受理し、大文字、ハイフンの欠落、長さの違う値を拒否する。これは PRD の要求 ID を持たない基盤の条件である。
- [ ] カーソルの符号化と復号が往復し、改ざんされた値と空の値を拒否する。
- [ ] 利用者に属するクエリを組み立てる関数が、`user_id` の条件を必ず含む。
- [ ] SQL の組み立てを D1 のバインディングなしで単体テストできる。
- [ ] 時刻を固定したテストで、UTC の文字列と日本時間の日付の変換を確かめる。日付の境界の性質は 0011 で追加する。
- [ ] `backend/warrior` の D1 の実行部分は、`wrangler dev` の結合テストで検証する。この issue では `users` の最小の表を使う。

## 解決方法

`migrations/0001_initial.sql` に `users` の最小の表を作る。
列は `id`、`google_sub`、`email`、`display_name`、`created_at`、`updated_at` とする。
認証の列の追加は 0015 で行う。
`backend/warrior_core/src/ids.rs` に UUID v4 の形式の検証を置く。
`backend/warrior_core/src/sql.rs` に SQL とバインド値の型、`user_id` の条件を必須にする型を置く。
`backend/warrior_core/src/cursor.rs` にカーソルの符号化と復号を置く。
`backend/warrior_core/src/datetime.rs` に UTC の文字列の整形と比較を置く。
`backend/warrior/src/db.rs` に D1 の `prepare` と `batch` の薄いラッパーを置く。
`backend/pbt/tests/` に UUID とカーソルの性質テストを置く。
`backend/warrior/tests/` に `wrangler dev` を使うマイグレーションの結合テストを置く。
