# 目標カロリーと PFC の画面と設定を実装する

- Requirements: REQ-PRG-007, REQ-PRG-010, REQ-PRG-011, REQ-PRG-013, REQ-PRG-014, REQ-PRG-015, REQ-PRG-016, REQ-PRG-018, REQ-MYP-002
- Priority: Medium
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-calorie-pfc-ui
- Completed: 2026-11-17

## 目的

日常の活動量を選べるようにし、目標カロリーと PFC の目安をプログラムの画面に表示する。
身体情報、目的、日常の活動量、週あたりのトレーニング可能日数を更新したら目安を計算し直し、未入力の項目がある場合は計算せずに入力を促す。
医療上の助言ではない旨と、ダイエットの減量の速さの目安を表示し、PFC の配分を調整して既定値に戻せるようにする。

## 優先度根拠

目標カロリーと PFC は段階 3 の機能であり、身体情報と目的の設定の後に作る。
計算の関数は 0013 にあるため、この issue は入力、表示、保存、案内を担う。

## 現状

0013 で目標カロリーと PFC の計算、0043 で身体情報、目的、週あたりの日数、活動量の保存を実装する。
しかし、目標カロリーと PFC の画面、活動量の選択、未入力の案内、注意書き、PFC の調整、既定値への復帰がない。

## 設計方針

目標カロリーと PFC の目安は、プログラムの画面に表示する。
プログラムを選んでいなくても、同じ値を確認できる。
マイページの栄養の画面でも同じ値を表示し、PFC の配分を調整できる。

日常の活動量は、低い、普通、高いの 3 つから 1 つを選んで保存する。
身体情報、目的、日常の活動量、週あたりのトレーニング可能日数のいずれかが未入力の場合は、目標カロリーと PFC の目安を表示せず、未入力の項目の入力を促す。
全ての項目がそろうと、計算結果を表示する。

身体情報、目的、日常の活動量、週あたりのトレーニング可能日数のいずれかを更新すると、表示中の目標カロリーと PFC の目安を新しい値で計算し直す。
PFC の調整値は保存し、身体情報、目的、日常の活動量、週あたりのトレーニング可能日数の更新で計算し直すときも保つ。
ただし、たんぱく質の範囲は体重に依存するため、体重の更新で範囲外になった場合は、範囲の境界の値に直し、その旨を表示する。

PFC の調整は、たんぱく質を体重 1 kg あたり 1.6 g から 2.2 g の範囲で指定し、脂質を目標カロリーに対する割合で指定する。
炭水化物は残りから計算して表示する。
たんぱく質と脂質の合計が目標カロリーを超える指定を受け付けない。
既定値に戻す操作は、たんぱく質を 2.0 g/kg、脂質を 20% に戻す。

目標カロリーと PFC の目安の近くに、表示する値が目安であり医療上や栄養指導上の助言ではない旨を表示する。
持病がある場合と妊娠中の場合は専門家に相談する旨も、同じ画面に表示する。
目的がダイエットのときは、カロリーの目安の近くに、週あたり体重の 0.5% から 1% の減量を目安として表示する。
目的がダイエット以外のときは、この目安を表示しない。
体重の推移の記録と、目安を守れているかの判定は表示しない。

数値は、目標カロリーを kcal の整数、PFC を g の整数で表示する。
丸めは、たんぱく質と脂質を四捨五入し、炭水化物を残りから計算して四捨五入する。
3 つのグラム数をカロリーに換算した合計と目標カロリーの差が、丸めの誤差の範囲に収まることを確かめる。

## 完了条件

- [ ] 日常の活動量の選択肢が低い、普通、高いの 3 つで、そのうち 1 つを選んで保存できる。これは REQ-PRG-007 の受入基準に対応する。
- [ ] 身体情報、目的、日常の活動量、週あたりのトレーニング可能日数のいずれかを更新すると、表示中の目標カロリーと PFC の目安が新しい値で計算し直される。これは REQ-PRG-010 の受入基準に対応する。
- [ ] プログラムの画面に、目標カロリーと PFC の目安が表示される。プログラムを選んでいない状態でも、同じ値を確認できる。これは REQ-PRG-011 の受入基準に対応する。
- [ ] 身体情報のいずれかの項目、目的、日常の活動量、週あたりのトレーニング可能日数が未入力のとき、目標カロリーと PFC の目安を表示せず、未入力の項目の入力を促す。全ての項目がそろうと、計算結果を表示する。これは REQ-PRG-013 の受入基準に対応する。
- [ ] 目標カロリーと PFC の目安の近くに、医療上や栄養指導上の助言ではない旨を表示する。持病がある場合と妊娠中の場合は専門家に相談する旨も、同じ画面に表示する。これは REQ-PRG-014 の受入基準に対応する。
- [ ] たんぱく質を体重 1 kg あたり 1.6 g から 2.2 g の範囲で指定でき、脂質を目標カロリーに対する割合で指定できる。炭水化物のグラム数を、残りから計算して表示する。これは REQ-PRG-015 の受入基準に対応する。
- [ ] 調整した PFC の配分は保存され、身体情報、目的、日常の活動量、週あたりのトレーニング可能日数を更新して目安を計算し直しても保たれる。既定値に戻す操作を行うと、たんぱく質が体重 1 kg あたり 2.0 g、脂質が目標カロリーの 20% に戻る。たんぱく質と脂質の合計が目標カロリーを超える指定を受け付けない。これは REQ-PRG-016 の受入基準に対応する。
- [ ] 目的がダイエットのとき、カロリーの目安の近くに、週あたり体重の 0.5% から 1% の減量を目安として表示する。目的がダイエット以外のときは表示しない。体重の推移の記録と、目安を守れているかの判定を表示しない。これは REQ-PRG-018 の受入基準に対応する。
- [ ] マイページで PFC の配分を調整できる。既定値に戻す操作を行うと、計算ルールの既定値に戻る。これは REQ-MYP-002 の受入基準に対応する。
- [ ] 体重の更新でたんぱく質の範囲が変わった場合、範囲の境界の値に直し、その旨を表示する。
- [ ] 例示テストで、活動量の 3 つ、未入力の組み合わせ、目的の 5 つ、ダイエットの目安、PFC の境界、既定値への復帰、体重の更新を確かめる。
- [ ] PBT で、表示する PFC のグラム数のカロリー換算の合計が、丸めの誤差の範囲で目標カロリーに一致することを確かめる。
- [ ] E2E で、活動量を選び、身体情報を更新し、PFC を調整し、既定値に戻し、注意書きとダイエットの目安を確かめる。

## 解決方法

`backend/warrior_core/src/nutrition.rs` に、PFC の調整値の保持、体重の更新による範囲の補正、表示用の丸めを追加する。
`backend/warrior/src/nutrition.rs` に、目標カロリーと PFC の取得と調整の保存を置く。
`backend/warrior/src/router.rs` に `GET /api/nutrition`、`PUT /api/nutrition` を追加する。
`frontend/src/screens/routines.rs` に目標カロリーと PFC の表示を置く。
`frontend/src/screens/mypage.rs` に栄養の画面と PFC の調整を置く。
`frontend/src/text.rs` に注意書きとダイエットの目安の文言を追加する。
`backend/warrior/tests/e2e_nutrition.rs` に E2E を追加する。
`backend/pbt/tests/nutrition_ui.rs` に丸めの性質テストを置く。

## 結果

`GET /api/nutrition` と `PUT /api/nutrition` を追加し、身体情報、目的、活動量、週あたりの日数から目標カロリーと PFC を計算する。
未入力の項目、医療上の注意、ダイエットの減量の目安、PFC の調整と既定値への復帰、体重による範囲の補正を画面に表示する。
`backend/warrior/tests/nutrition.rs` で計算、保存、範囲外の拒否を確認し、`backend/pbt/tests/nutrition_ui.rs` で丸めの合計を確認した。
`backend/warrior/tests/e2e_nutrition.rs` で、目標カロリーと PFC、ダイエットの目安、注意書き、PFC の調整と既定値への復帰を実ブラウザで確認した。
