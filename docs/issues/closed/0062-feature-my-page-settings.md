# マイページの設定と表示モードを実装する

- Requirements: REQ-MYP-001, REQ-MYP-002, REQ-MYP-003, REQ-MYP-005, REQ-NFR-012, REQ-NFR-019
- Priority: High
- Completed: 2026-11-15
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-my-page-settings

## 目的

マイページに、プロフィール、栄養、記録、表示、データ、アカウントの設定をまとめる。
レスト時間の既定値、画面の消灯防止、ブラウザ通知を設定できるようにし、表示モードをライト、ダーク、端末の設定に合わせるの 3 つから選べるようにする。
設定を保存し、再読み込みの後も保つ。

## 優先度根拠

マイページの基本は段階 1 の機能であり、記録の設定と身体情報の入口になる。
表示モードは段階 4 の機能であり、0005 のデザイントークンと各画面の配色の後に作る。

## 現状

0043 でプロフィール、0054 で栄養、0034 でレスト時間と消灯防止、0035 でブラウザ通知、0036 でプッシュ通知の設定の部品を実装する。
しかし、マイページのまとめ、設定の保存、表示モードの切り替え、再読み込みの後の復元がない。

## 設計方針

マイページは、プロフィール、栄養、記録、表示、データ、アカウントの 6 つの区分を持つ。
0043 がマイページにプロフィールの区分を実装する。0062 は同じ区分を重複して作らず、その画面に設定の区分を追加する。
プロフィールは 0043、栄養は 0054、データは 0064、アカウントは 0063 の画面を開く。
記録の区分に、レスト時間の既定値、画面の消灯防止、ブラウザ通知、プッシュ通知の設定を置く。
表示の区分に、表示モードの設定を置く。

利用者共通の設定は、利用者ごとに 1 行を持つ。
項目は、レスト時間の既定値と表示モードとする。
画面の消灯防止、ブラウザ通知、プッシュ通知は端末ごとの設定とし、端末内に保存する。
設定を変更すると保存し、再読み込みの後も同じ値を表示する。
レスト時間の既定値は 1 秒以上 3600 秒以下とする。
ブラウザ通知とプッシュ通知の設定は、利用者が有効にしたときにだけ、ブラウザの許可を求める。

表示モードは、ライト、ダーク、端末の設定に合わせるの 3 つとする。
端末の設定に合わせる場合は、`prefers-color-scheme` の値に従う。
アプリ内で手動で切り替えた場合は、その値を保存し、端末の設定より優先する。
初期状態は端末の設定に合わせる。
保存した表示モードは、初期表示のための端末内の保存にも書き、設定の取得を待たずに同じモードで表示する。
テーマの属性は 0005 の生成物を使い、ルート要素の属性を切り替える。

ライトとダークの両方で、部位の色分けとグラフを判別できる配色にする。
0005 の生成した部位の色とグラフの色を使い、`mark` と `primary` の色を `surfaceRaised` の上の文字に使わない。
押せる要素の最小 44px と、文字の最小 11px を守る。

設定の変更は、端末内の保存と送信待ちの列を通る。
テーマの切り替えは、設定が読み込まれる前に端末の設定で表示し、設定が読み込まれた後に保存した値へ切り替える。

## 完了条件

- [ ] マイページで、身体情報、目的、週あたりのトレーニング可能日数、日常の活動量を確認できる。それぞれを更新すると保存され、ほかの画面の表示も新しい値に変わる。これは REQ-MYP-001 の受入基準に対応する。
- [ ] マイページで PFC の配分を調整できる。既定値に戻す操作を行うと、計算ルールの既定値に戻る。これは REQ-MYP-002 の受入基準に対応する。
- [ ] マイページで、レスト時間の既定値、画面の消灯防止、ブラウザ通知の 3 つを設定できる。設定した値は保存され、再読み込みの後も保たれる。これは REQ-MYP-003 の受入基準に対応する。
- [ ] 表示モードを、ライト、ダーク、端末の設定に合わせるの 3 つから選べる。選んだモードは保存され、再読み込みの後も同じモードで表示される。これは REQ-MYP-005 の受入基準に対応する。
- [ ] ライトモードとダークモードの両方で画面を表示できる。初期状態は端末の設定に合わせ、アプリ内で手動でも切り替えられる。部位の色分けとグラフは、どちらのモードでも部位を判別できる配色になる。これは REQ-NFR-012 の受入基準に対応する。
- [ ] ブラウザ通知とプッシュ通知の許可を、利用者が有効にしたときにだけ求める。
- [ ] レスト時間の既定値が 1 秒以上 3600 秒以下であり、範囲外の値を拒否する。
- [ ] 設定が利用者ごとに保存され、別の利用者の設定と混ざらない。レスト時間の既定値と表示モードは利用者共通、画面の消灯防止、ブラウザ通知、プッシュ通知は端末ごとに保存され、別の端末に同期されない。
- [ ] 利用者共通の設定の変更が、端末内の保存と送信待ちの列を通る。端末ごとの設定は端末内に保存し、送信待ちの列に積まない。
- [ ] ブラウザのテストで、3 つの表示モード、端末の設定の変更への追従、再読み込みの後の復元を確かめる。
- [ ] ブラウザのテストで、ライトとダークの両方の部位の色とグラフの色のコントラストを確かめる。
- [ ] ブラウザのテストで、押せる要素の最小 44px と文字の最小 11px を確かめる。
- [ ] 例示テストで、設定の保存と復元、レスト時間の境界、表示モードの 3 つ、通知の許可の要求の条件を確かめる。
- [ ] E2E で、マイページを開き、レスト時間と通知を設定し、表示モードを切り替え、再読み込みの後も保たれることを確かめる。

## 解決方法

`migrations/` に `user_settings` の表を追加する。表はレスト時間の既定値と表示モードを持つ。
`frontend/src/storage/settings.rs` に、画面の消灯防止、ブラウザ通知、プッシュ通知の端末ごとの設定を保存する。
`backend/warrior_core/src/settings.rs` に、設定の型、表示モード、レスト時間の検証を置く。
`backend/warrior/src/settings.rs` に、設定の取得と更新を置く。
`backend/warrior/src/router.rs` に `GET /api/settings`、`PUT /api/settings` を追加する。
`frontend/src/screens/mypage.rs` に 6 つの区分と設定を置く。
`frontend/src/theme.rs` に表示モードの切り替えと端末の設定の追従を置く。
`frontend/src/text.rs` に設定の文言を追加する。
`frontend/tests/settings.rs` にブラウザのテストを追加する。
`backend/warrior/tests/e2e_settings.rs` に E2E を追加する。
`backend/warrior_core/src/account_deletion.rs` の表の一覧に `user_settings` を追加する。
