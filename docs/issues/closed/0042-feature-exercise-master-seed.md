# 種目マスターの初期データを投入する

- Requirements: REQ-LIB-001, REQ-LIB-004, REQ-LIB-011, REQ-LIB-012
- Priority: High
- Created: 2026-11-12
- Completed: 2026-11-14
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-exercise-master-seed

## 目的

種目ライブラリに、100 種以上 110 種以下の代表的な種目をマスターとして登録する。
15 本のプログラムの主な種目を同じ部位区分かつ同じ記録方式で表現できるように含め、その他を除く部位区分ごとに主要な器具の定番種目をそろえる。

## 優先度根拠

種目マスターの初期データがないと、ライブラリと記録の種目の選択が空になる。
段階 2 の人体図と段階 3 のプログラムも、このデータに依存する。

## 現状

0019 で種目マスターの表と型、0039 で一覧と詳細、0040 で独自種目と上書きを実装する。
PRD の「付録: 種目マスターの初期登録案」で、103 種目の主働筋と補助筋、使用器具、記録方式を決めた。
しかし、マスターの種目のデータが 1 件もない。

## 設計方針

PRD の付録の 103 種目を初期データとする。
種目名、読み、部位区分、狙う部位、補助筋、使用器具、記録方式、左右別の可否、グリップの選択肢は、付録の表に従う。
読みは、付録の名称に対応する五十音順の読みを投入する。
主働筋は、付録の「狙う部位」を登録する。
補助筋は、付録の「補助筋」を登録する。
補助筋が「なし」の種目は、補助筋を空にする。

15 本のプログラムの主な種目それぞれに、同じ部位区分かつ同じ記録方式の種目が 103 種に含まれる。
プログラムの日ごとの種目は 0046 が種目マスターから選ぶ。
15 本のプログラムは、この issue の 103 種の範囲で組む。
0046 は 0042 の種目マスターにない種目を使わない。
不足する場合は、同じ部位区分かつ同じ記録方式の別の種目に置き換える。

部位区分ごとに、バーベル、ダンベル、マシン、ケーブル、自重の定番種目をそろえる。ただし、その他は筋肉の単位を持たない種目だけを置く。
部位区分は、胸、背中、肩、二頭・前腕、三頭、脚、腹筋、その他の 8 つとする。
その他の種目は筋肉の単位を持たず、狙う部位の代わりに全身か下半身かを登録する。
筋肉の単位は、0019 の 24 個のうち、付録の「狙う部位」と「補助筋」に対応するものを使う。

初期データはマイグレーションで投入する。
データの変更は、新しいマイグレーションで行う。
ID は UUID v4 とし、固定の値をマイグレーションに書く。
削除した種目の ID を再利用しない。

## 完了条件

- [ ] 種目ライブラリに 100 種以上 110 種以下の種目が登録されている。これは REQ-LIB-001 の受入基準に対応する。
- [ ] 15 本のプログラムの主な種目が、103 種の範囲で同じ部位区分かつ同じ記録方式の種目として表現できる。15 本のプログラムの種目が 0042 の種目マスターに含まれることは 0046 が確かめる。これは REQ-LIB-001 の受入基準に対応する。
- [ ] その他を除く部位区分ごとに、バーベル、ダンベル、マシン、ケーブル、自重の定番種目がそろっている。その他は筋肉の単位を持たない種目だけを含む。これは REQ-LIB-001 の受入基準に対応する。
- [ ] 各種目の名称、読み、部位区分、使用器具、記録方式、左右別の可否、グリップの選択肢が、PRD の付録の表と一致する。読みは五十音順の並べ替えに使える。
- [ ] その他を除く各種目の主働筋が、付録の「狙う部位」と一致する。その他の種目は筋肉の単位を持たず、全身か下半身かが付録と一致する。
- [ ] 補助筋が、付録の「補助筋」と一致する。補助筋が「なし」の種目は、補助筋が空である。
- [ ] 初期データの投入がマイグレーションで行われ、同じマイグレーションを 2 回適用しても重複しない。
- [ ] 投入した種目の並びが、部位区分、使用器具、種目名の五十音順の昇順になる。
- [ ] 結合テストで、種目の件数、部位区分ごとの器具の種類、主な種目または同じ部位区分かつ同じ記録方式の代替の存在を確かめる。
- [ ] データの整合は、投入の SQL と種目の型の検証で確かめる。PBT は、データが固定であるため使わない。

## 解決方法

`migrations/` に種目マスターの初期データの SQL を追加する。各 103 種に名称と読みを含める。
`backend/warrior/tests/exercise_seed.rs` に、件数、その他を除く部位区分ごとの器具、主な種目または同じ部位区分かつ同じ記録方式の代替の存在、補助筋の整合、読みによる五十音順の並びを確かめる結合テストを置く。
0046 は 0042 のマスターにある種目だけを使う。0042 に種目を追加しない。

## 結果

PRD の付録の 103 種に、器具の網羅のため 3 種 (パイクプッシュアップ、インバーテッドカール、バーベルロールアウト) を加えた 106 種を投入した。`migrations/0009_exercise_master_seed.sql` に 106 種の名称、読み、部位区分、器具、記録方式、左右別、グリップ、24 個の筋肉の単位と 281 行の主働筋と補助筋を入れた。追加の 3 種は、付録の 103 種にない「肩と自重」「二頭・前腕と自重」「腹筋とバーベル」の組を満たすためである。15 本のプログラムの主な種目 37 種は、付録の 103 種の範囲で同名または同じ部位区分と記録方式の種目が存在する。
`Exercise::validate` を「主働筋の 1 つ以上が種目の部位区分に一致する」に緩和した。付録の補助筋が他部位を含み、アップライトロウとフェイスプルの主働筋に僧帽筋が入るためである。0019 の「部位区分と筋肉の単位が合わない種目を拒否する」は、主働筋の全部が他部位の場合を拒否する意味に読み替える。0039 と 0040 はこの規則に従う。
やり方、注意点、コツは付録にないため空とし、0075 で書く。
`mise.toml` の `test-integration` に `exercise_seed` を追加し、`CHANGES.md` の `## develop` に 106 種の投入を追記した。
