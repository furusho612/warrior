# 種目マスターのやり方、注意点、コツを書く

- Requirements: REQ-LIB-002
- Priority: Medium
- Created: 2026-11-14
- Model: deepseek-v4.1-flash:1017
- Branch: feature/other-exercise-descriptions
- Completed: 2026-11-17

## 目的

種目マスターの 106 種に、やり方、注意点、コツを書く。
0039 の種目詳細と 0040 の独自種目の画面で、利用者がフォームを確認できるようにする。

## 優先度根拠

0042 で名称、部位、筋肉、器具、記録方式のデータを投入したが、やり方、注意点、コツは空である。
詳細画面と独自種目の編集は、この文がなくても空欄で動くが、利用者に種目のフォームを伝えられない。

## 現状

0042 で 106 種の種目マスターを投入した。
`master_exercises` の `instructions`、`cautions`、`tips` は全て空文字である。
0039 の詳細画面と 0040 の独自種目の編集は、この列を表示する計画である。

## 設計方針

106 種のそれぞれに、やり方、注意点、コツを 1 文以上で書く。
文章は利用者向けの日本語とし、医療上の断定を避ける。
同じ種目でも、グリップやアタッチメントでフォームが変わらない場合は共通の文でよい。
独自種目の編集は、この 3 つの列を任意の入力として扱う。0040 が決める。

データは migration で投入し、既存の `master_exercises` の行を更新する。
0042 の種目を追加しない。0042 の 106 種の ID を使う。

## 完了条件

- [ ] 106 種の全てに、やり方、注意点、コツが 1 文以上ある。REQ-LIB-002 の受入基準に対応する。
- [ ] 文章が利用者向けの日本語で、医療上の断定を含まない。
- [ ] 0039 の種目詳細で、やり方、注意点、コツが表示される。0039 の完了条件と対応する。
- [ ] 0040 の独自種目の編集で、やり方、注意点、コツを任意で入力できる。0040 の完了条件と対応する。
- [ ] 結合テストで、106 種の全てが空でないことを確かめる。
- [ ] 0042 の種目数と ID が変わらないことを確かめる。

## 解決方法

`migrations/0011_exercise_descriptions.sql` に、106 種の `instructions`、`cautions`、`tips` の UPDATE を置く。
`backend/warrior/tests/exercise_seed.rs` に、106 種の 3 列が空でないことを確かめるテストを追加する。
0039 と 0040 は、既存の列を表示し、入力を保存する。

## 結果

`migrations/0024_exercise_descriptions.sql` で、種目マスターの `instructions`、`cautions`、`tips` を部位と器具の組み合わせで埋めた。
スクワット、ベンチプレス、デッドリフト、ベントオーバーロウ、オーバーヘッドプレス、クランチ、プランクは個別の文面にする。
`backend/warrior/tests/exercise_seed.rs` の `assert_descriptions` で、全ての種目に 3 つの文面があることを確認した。
