# 過去のトレーニングの編集、削除、日付指定の追加を実装する

- Requirements: REQ-REC-006, REQ-NFR-019
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-past-record-edit

## 目的

過去のトレーニングのセットを編集し、削除できるようにする。
日付を指定して後から記録を追加できるようにする。
編集と削除を履歴とカレンダーに反映し、影響する自己ベストを計算し直す。

## 優先度根拠

過去の記録の編集と削除は、カレンダー、分析、自己ベスト、AI の入力の値を変える。
編集の経路を後から足すと、自己ベストとカレンダーの更新が漏れる。

## 現状

0022 でトレーニングの終了とサマリー、0024 から 0031 で種目とセットの機能、0029 で自己ベストを実装する。
しかし、終了したトレーニングを開いて編集する経路、削除の経路、日付を指定して追加する経路がない。

## 設計方針

終了したトレーニングは、記録画面と同じ部品で開き、種目、セット、メモを編集できる。
自重種目のセットを編集するときは、記録時点の体重 `sets.body_weight_kg` を変えず、`set_segments.weight_kg` のセットごとの加重だけを更新する。重量は読み取り時に記録時点の体重と加重の和で求める。
編集の保存は、サーバーが受理した時刻で後勝ちとする。
端末の時計ではなく、サーバーが受理した時刻で決める。

トレーニングを削除すると、そのトレーニングの種目、セット、段、組も削除する。
履歴とカレンダーから消える。
AI の評価と次回セットの提案は、生成時の記録に基づくため、自動で作り直さない。ADR-009 の判断に従う。

日付を指定して追加するトレーニングは、日本時間の日付と所要時間を持ち、開始時刻を持たない。
日付は 0011 の `JstDate` で検証する。
追加した記録は、指定した日付のトレーニングとしてカレンダーに現れる。
所要時間は秒の整数とし、1 秒以上 86400 秒以下とする。

編集と削除で自己ベストが変わる場合は、影響する種目とグリップの組について、残っている全ての記録から自己ベストを計算し直す。
計算し直した結果、値がなくなる場合は、その自己ベストの行を削除する。
対象は、編集または削除したトレーニングの種目とする。
自己ベストの計算し直しは、0029 の判定の関数を使う。

編集と削除と追加は、端末内の保存と送信待ちの列を通る。
終了したトレーニングは編集権を持たないため、同じアカウントのどの端末からでも編集できる。0023 の規則に従う。

## 完了条件

- [ ] 過去のトレーニングのセットを編集すると、編集後の内容が保存され、履歴とカレンダーにも反映される。これは REQ-REC-006 の受入基準に対応する。
- [ ] トレーニングを削除すると、一覧とカレンダーから消える。これは REQ-REC-006 の受入基準に対応する。
- [ ] 日付を指定して追加した記録が、指定した日付のトレーニングとしてカレンダーに現れる。これは REQ-REC-006 の受入基準に対応する。
- [ ] 日付を指定して追加したトレーニングが、開始時刻を持たず、指定した所要時間を持つ。
- [ ] 終了したトレーニングの編集が、同じアカウントのどの端末からでもでき、同時の編集は後から保存した内容が残る。
- [ ] 編集と削除の後に、影響する種目とグリップの組の自己ベストが、残っている全ての記録から計算し直される。
- [ ] 自己ベストの値がなくなった場合、その行が削除される。
- [ ] AI の評価と次回セットの提案が、編集と削除で自動的に作り直されない。
- [ ] 編集、削除、追加が、端末内の保存と送信待ちの列を通る。
- [ ] 存在しない日付、86400 秒を超える所要時間、空の編集を拒否する。
- [ ] PBT で、自己ベストの計算し直しが、編集と削除の前後で、残っている記録から計算した値と一致することを確かめる。
- [ ] 例示テストで、セットの編集、トレーニングの削除、日付指定の追加、自己ベストがなくなる削除を確かめる。
- [ ] 結合テストで、編集と削除の後に、履歴とカレンダーの取得が変わることを確かめる。
- [ ] 別のアカウントのトレーニング ID を指定した編集、削除、日付指定の追加が 404 になる。0015 の所有者検査を使う。
- [ ] E2E で、過去の記録を編集し、削除し、日付を指定して追加する操作を確かめる。

## 解決方法

`backend/warrior/src/training_session.rs` に、終了したトレーニングの編集、削除、日付指定の追加を置く。
`backend/warrior_core/src/personal_best.rs` に、全ての記録から自己ベストを計算し直す関数を置く。
`backend/warrior/src/stored_sets.rs` の読み取りは、自重種目の重量を `sets.body_weight_kg` と `set_segments.weight_kg` の和で求める。
`backend/warrior/src/personal_best.rs` に、対象の種目の自己ベストを計算し直す処理を置く。
`frontend/src/screens/record.rs` に、終了したトレーニングの編集の表示を置く。
`frontend/src/screens/history.rs` に、編集と削除の操作を置く。
`frontend/src/screens/calendar.rs` に、日付指定の追加の入口を置く。カレンダーの表示は 0048 が担う。
`backend/warrior/tests/e2e_record_edit.rs` に E2E を追加する。
`backend/pbt/tests/personal_best_rebuild.rs` に性質テストを置く。
