# 種目別の履歴とグラフ、自己ベストを実装する

- Requirements: REQ-ANL-001, REQ-ANL-002, REQ-ANL-003, REQ-ANL-004, REQ-LIB-008
- Priority: Medium
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-exercise-history-graph

## 目的

種目ごとに、過去の記録を新しい順に表示し、最大重量、推定 1RM、総重量の推移のグラフを、1 か月、3 か月、6 か月、1 年、全期間の期間で切り替えて表示する。時間の種目では、最長時間と合計時間を表示する。
種目ごとの自己ベストと達成日を表示する。

## 優先度根拠

種目別の履歴とグラフは、段階 2 の振り返りの中心であり、目標重量の達成の判断にも使う。
指標と期間の定義を先に固定しないと、グラフの値が記録の計算と食い違う。

## 現状

0012 で推定 1RM と総重量、0029 で自己ベスト、0031 でグリップの絞り込み、0032 で過去の記録の編集を実装する。
0039 で種目の詳細から履歴とグラフを開く入口を用意する。
しかし、履歴の一覧、グラフ、期間の切り替え、自己ベストと達成日の表示がない。

## 設計方針

履歴は、種目ごとに過去の記録を新しい順に表示する。
各セットには、重量、回数または時間、セット種別、グリップとアタッチメント、RPE、反動と補助の回数を表示する。
記録の日付は 0011 の `JstDate` を使う。
同じ日の複数のトレーニングは、終了の時刻の新しい順に並べる。

グラフの指標は、重量と回数の種目では最大重量、推定 1RM、総重量の 3 つとする。
時間の種目では、最長時間と合計時間の 2 つとする。左右別の時間種目は、最長時間を左右の最大値、合計時間を左右の和とする。
指標は画面上で切り替えられる。
グラフの値は、0012 の計算を使う。
最大重量と推定 1RM は、ドロップセットの最初の段だけを対象にする。
総重量は、ウォームアップを除き、ドロップセットの全段を含め、左右別を合算し、反動を含め、補助を含めない。

グラフの期間は、1 か月、3 か月、6 か月、1 年、全期間の 5 つとする。
期間の終わりは、表示の時点の日本時間の日付とする。
期間の始まりは、その日から 1 か月、3 か月、6 か月、1 年を引いた日とする。
全期間は、全ての記録を含む。
期間を変えると、グラフに含まれる記録の範囲がその期間に変わる。

自己ベストは、0029 の値を表示する。
最大重量、推定 1RM、種目別の総重量と、その達成日を表示する。
時間の種目では、左右を区別しない最長時間と達成日を表示する。
グリップとアタッチメントで絞り込んだ場合は、その組の自己ベストを表示する。

グラフはフロントエンドで SVG を描く。
集計はサーバーで行い、期間と指標に応じた点を返す。ADR-016 に従う。
点は、日付と値を持つ。
同じ日に複数の記録がある場合は、その日の指標の値を 1 点にまとめる。最大重量と推定 1RM と最長時間は最大値、総重量と合計時間は合計とする。

目標重量の線と現在の記録との差は 0053 が追加する。

## 完了条件

- [ ] 種目ごとの履歴に、過去の記録が新しい順に並ぶ。各セットには、重量、回数または時間、セット種別、グリップとアタッチメント、RPE、反動と補助の回数が表示される。これは REQ-ANL-001 の受入基準に対応する。
- [ ] 種目ごとのグラフで、最大重量、推定 1RM、総重量の指標を切り替えられる。時間で記録する種目では、最長時間と合計時間の指標を切り替えられる。左右別の時間種目では、最長時間が左右の最大値、合計時間が左右の和になる。これは REQ-ANL-002 の受入基準に対応する。
- [ ] グラフの期間を 1 か月、3 か月、6 か月、1 年、全期間の 5 つから選べる。期間を変えると、グラフに含まれる記録の範囲がその期間に変わる。これは REQ-ANL-003 の受入基準に対応する。
- [ ] 種目ごとに、最大重量、推定 1RM、種目別の総重量の自己ベストと、その達成日が表示される。時間で記録する種目では、左右を区別しない最長時間とその達成日が表示される。これは REQ-ANL-004 の受入基準に対応する。
- [ ] 種目の詳細から、その種目の履歴とグラフの画面を開ける。これは REQ-LIB-008 の受入基準に対応する。
- [ ] 履歴の並びが、日付の新しい順で、同じ日は終了の時刻の新しい順になる。
- [ ] グラフの値が 0012 の計算と一致し、ドロップセット、ウォームアップ、左右別、反動と補助の扱いが正しい。
- [ ] 同じ日の複数の記録が、指標に応じて最大値または合計の 1 点にまとまる。
- [ ] グリップとアタッチメントで絞り込むと、その組の記録と自己ベストが表示される。
- [ ] グラフがライトとダークの両方で判別できる。
- [ ] PBT で、期間の選択が、期間の始まり以降の記録だけを返し、期間の外の記録を返さないことを確かめる。
- [ ] PBT で、グラフの点が 0012 の計算と一致し、同じ日の複数の記録のまとめ方が指標に従うことを確かめる。
- [ ] 例示テストで、5 つの期間、5 つの指標、時間の種目、同じ日の複数の記録、記録がない期間を確かめる。
- [ ] E2E で、種目の詳細から履歴とグラフを開き、期間と指標を切り替え、自己ベストを確かめる。

## 解決方法

`backend/warrior_core/src/history.rs` に、期間の範囲、指標の計算、同じ日の点のまとめを置く。
`backend/warrior/src/history.rs` に、履歴とグラフの点と自己ベストの取得を置く。
`backend/warrior/src/router.rs` に `GET /api/exercises/:id/history`、`GET /api/exercises/:id/graph` を追加する。
`frontend/src/screens/exercise.rs` に履歴とグラフを置く。
`frontend/src/graph.rs` に SVG のグラフを置く。
`backend/warrior/tests/e2e_history.rs` に E2E を追加する。
`backend/pbt/tests/history.rs` に性質テストを置く。
