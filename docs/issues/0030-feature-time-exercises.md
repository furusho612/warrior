# 時間で記録する種目を実装する

- Requirements: REQ-SET-010, REQ-NFR-019
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-time-exercises

## 目的

時間で記録する種目で、セットごとに時間を記録できるようにする。
ストップウォッチで計った時間をそのまま記録する経路と、手入力する経路を用意する。
重量、回数、反動と補助の回数の欄を表示せず、RPE は記録できるようにする。

## 優先度根拠

時間で記録する種目は、総重量と推定 1RM の対象外であり、自己ベストとグラフの指標が変わる。
記録方式によって入力欄と集計を切り替える構造を先に固定しないと、種目ごとの分岐が画面に散る。

## 現状

0019 で時間で記録する種目を表せるようにし、0025 から 0029 で重量と回数のセットの機能を実装する。
しかし、時間の入力、ストップウォッチ、手入力、時間で記録する種目の表示と集計がない。

## 設計方針

時間で記録する種目のセットは、時間を秒の整数で持つ。左右別の種目では、左右それぞれの時間を持つ。
時間は 1 秒以上 86400 秒以下とする。
上限を 86400 秒とするのは、1 日の秒数を超えるセットを記録の対象にしないためである。
重量、回数、反動の回数、補助の回数の欄を表示せず、値も保存しない。
RPE は記録できる。

ストップウォッチは、開始の時刻を端末内に保存し、停止したときに現在時刻との差から経過時間を求める。
残り時間を減算する状態を持たない。
再読み込みの後も、保存した開始時刻から経過時間を求められる。
ストップウォッチの計測中に端末の時計を変更した場合は、経過時間が変わる。この制約を画面に示さない。

手入力は、分と秒、または秒で入力できる。
`mm:ss` と秒の表記を解析し、秒の整数に変換する。
画面には `mm:ss` で表示する。

時間で記録する種目は、総重量と推定 1RM の対象外とする。
部位別のセット数には 1 セットとして数える。
自己ベストは、左右を区別しない最長時間とする。
前回比とグラフは、最長時間と合計時間で示す。左右別に行う時間で記録する種目は、最長時間を左右の最大値、合計時間を左右の和とする。グラフの実装は 0049 が担う。

## 完了条件

- [ ] 時間で記録する種目では、セットごとに時間を保存できる。これは REQ-SET-010 の受入基準に対応する。
- [ ] 左右別に行う時間で記録する種目では、左右それぞれの時間を保存できる。
- [ ] ストップウォッチで計った時間をそのまま記録する経路と、手入力する経路がある。これは REQ-SET-010 の受入基準に対応する。
- [ ] 重量、回数、反動と補助の回数の欄が表示されず、値も保存されない。これは REQ-SET-010 の受入基準に対応する。
- [ ] RPE を記録できる。
- [ ] ストップウォッチの計測中に再読み込みしても、保存した開始時刻から経過時間を求められる。
- [ ] 時間で記録するセットが、総重量と推定 1RM の対象外で、部位別のセット数に 1 と数えられる。
- [ ] 時間で記録する種目の自己ベストが、左右を区別しない最長時間になる。左右別に行う時間で記録する種目は、左右の最大値を最長時間とする。
- [ ] 1 秒未満と 86400 秒を超える時間を拒否する。
- [ ] PBT で、`mm:ss` と秒の解析と整形が往復し、任意の開始時刻と現在時刻から経過時間が一意に決まることを確かめる。
- [ ] 例示テストで、0 秒、1 秒、59 秒、60 秒、3599 秒、3600 秒、86400 秒を確かめる。
- [ ] E2E で、ストップウォッチを開始し、時間が進んだことを条件に停止し、手入力の経路とあわせて保存を確かめる。固定の `sleep` を書かない。
- [ ] ブラウザのテストで、再読み込みの後の経過時間の復元を確かめる。

## 解決方法

`backend/warrior_core/src/duration.rs` に、`mm:ss` と秒の解析、整形、経過時間の計算を置く。
`backend/warrior/src/set.rs` に時間で記録するセットの保存を追加する。左右別の種目では、`sets` に左右の時間の列を追加する。
`frontend/src/screens/record.rs` に、時間で記録する種目の入力、ストップウォッチ、手入力を置く。
`frontend/src/storage/stopwatch.rs` に、開始時刻の保存と復元を置く。
`frontend/tests/stopwatch.rs` にブラウザのテストを追加する。
`backend/warrior/tests/e2e_record_time.rs` に E2E を追加する。
`backend/pbt/tests/duration.rs` に性質テストを置く。
