# 種目ライブラリの一覧、詳細、検索、お気に入りを実装する

- Requirements: REQ-LIB-002, REQ-LIB-006, REQ-LIB-007, REQ-LIB-008
- Priority: High
- Created: 2026-11-12
- Model: deepseek-v4.1-flash:1017
- Branch: feature/feature-library-ui

## 目的

種目ライブラリの一覧を、部位区分、使用器具、種目名の五十音順で表示する。
部位区分、使用器具、お気に入り、名称の検索で絞り込めるようにする。
種目の詳細から、その種目の過去の履歴とグラフを開けるようにする。

## 優先度根拠

種目ライブラリは段階 1 の記録の入口であり、種目を選ぶ操作が記録の開始に直結する。
一覧の並びと絞り込みを先に固定しないと、記録の種目の選択とライブラリの画面で順序が食い違う。

## 現状

0019 で種目マスターの表と型、0024 で記録の種目の追加を実装する。
しかし、ライブラリの一覧、詳細、検索、絞り込み、お気に入り、履歴とグラフへの入口がない。

## 設計方針

一覧は、部位区分、使用器具、種目名の五十音順の昇順で並べる。
部位区分の順序は、胸、背中、肩、二頭・前腕、三頭、脚、腹筋、その他とする。
使用器具の順序は、バーベル、ダンベル、マシン、ケーブル、自重、その他とする。
種目名の比較は、`name_kana` を使う。

絞り込みは、部位区分、使用器具、お気に入り、名称の検索の 4 つとする。
複数の条件を同時に指定した場合は、全ての条件を満たす種目を返す。
名称の検索は、種目名と読みの部分一致とする。
絞り込んだ一覧も、上の並び順を保つ。

お気に入りは、利用者ごとに保存する。
マスターの種目と独自種目の両方をお気に入りにできる。
お気に入りだけの一覧には、登録した種目だけが並び、お気に入りから外すとその一覧から消える。

種目の詳細には、名称、部位区分、主働筋、補助筋、使用器具、やり方、注意点、コツを表示する。
主働筋と補助筋は、別の項目として区別して表示する。
人体図は 0041、自己ベストと目標重量は 0029 と 0053、履歴とグラフは 0049 が担う。
この issue では、それらの表示の場所と、履歴とグラフを開く経路を用意する。

一覧はカーソル方式でページングする。
1 ページの件数は環境ごとの vars に置く。

## 完了条件

- [ ] 各種目の詳細に、名称、部位区分、主働筋、補助筋、使用器具、やり方、注意点、コツが表示される。主働筋と補助筋が別の項目として区別して表示される。これは REQ-LIB-002 の受入基準に対応する。
- [ ] 種目をお気に入りに登録できる。お気に入りだけの一覧には、登録した種目だけが並び、お気に入りから外すとその一覧から消える。これは REQ-LIB-006 の受入基準に対応する。
- [ ] 部位区分、使用器具、お気に入り、名称の検索のそれぞれの条件で、種目の一覧を絞り込める。絞り込んだ一覧も、部位区分、使用器具、種目名の五十音順の昇順で並ぶ。これは REQ-LIB-007 の受入基準に対応する。
- [ ] 種目の詳細から、その種目の過去の履歴とグラフの画面を開ける。表示する内容は 0049 が担う。これは REQ-LIB-008 の受入基準のうち、画面を開けることを満たす。
- [ ] 一覧が、部位区分、使用器具、種目名の五十音順の昇順で並ぶ。
- [ ] 複数の絞り込みの条件を同時に指定すると、全ての条件を満たす種目だけが返る。
- [ ] お気に入りが利用者ごとに保存され、別の利用者のお気に入りと混ざらない。
- [ ] 一覧がカーソル方式でページングされ、続きのページが取得できる。
- [ ] 種目が 0 件のとき、空の一覧と案内を表示する。
- [ ] PBT で、絞り込みの結果が全ての条件を満たし、条件を満たす種目を落とさないことを確かめる。
- [ ] PBT で、一覧の並びが、部位区分、使用器具、読みの順序の比較と一致することを確かめる。
- [ ] 例示テストで、4 つの絞り込み、複数の条件、お気に入りの登録と解除、空の一覧を確かめる。
- [ ] E2E で、種目を検索し、絞り込み、お気に入りに登録し、詳細を開き、履歴とグラフの入口を確かめる。

## 解決方法

`migrations/` に `exercise_favorites` の表を追加する。種目の種別と種目 ID を持ち、利用者ごとに一意にする。
`backend/warrior/src/library.rs` に、一覧、詳細、絞り込み、お気に入りの取得と更新を置く。
`backend/warrior/src/router.rs` に `GET /api/exercises`、`GET /api/exercises/:id`、`PUT /api/exercises/:id/favorite`、`DELETE /api/exercises/:id/favorite` を追加する。
`frontend/src/screens/library.rs` に一覧、検索、絞り込み、お気に入りを置く。
`frontend/src/screens/exercise.rs` に詳細を置く。
`frontend/src/text.rs` に部位区分、使用器具、お気に入りの文言を追加する。
`backend/warrior/tests/e2e_library.rs` に E2E を追加する。
`backend/pbt/tests/library.rs` に性質テストを置く。
`backend/warrior_core/src/account_deletion.rs` の表の一覧に `exercise_favorites` を追加する。
