# ADR-001: Web アプリをインストール可能な PWA として提供する

- Status: Accepted

## Context

対象の環境は、スマートフォンの Safari と Chrome、PC の Chrome と Safari の最新版である (REQ-NFR-001)。
ネイティブアプリは対象外である。
レスト終了の通知は、画面を消灯した状態やブラウザを閉じた状態でも届ける必要がある (REQ-TMR-008)。
iOS では、ホーム画面に追加した場合に限り、この通知が届く。
ロック画面でのタイマー常時表示は対象外である。
Web ブラウザでは実現できない。
記録中のトレーニングは、入力のたびに端末内へ保存し、通信が切れても入力を続けられる必要がある (REQ-NFR-003)。
未接続の状態でアプリを開くことと、過去の記録を未接続で閲覧することは対象外である。

## Decision

単一の Web アプリを **PWA** として提供する。
PWA は、ホーム画面に追加して起動できる Web アプリを指す。
アプリは Web App Manifest と Service Worker を持ち、ホーム画面に追加した場合はブラウザの画面を隠して起動する。
ネイティブのラッパーや、別のプラットフォーム向けのビルドは持たない。

Service Worker は、プッシュ通知の受信と、アプリの静的なファイルの配信を担う。
記録データの保存は Service Worker に依存させず、端末内の永続ストレージへ直接書く。

iOS でプッシュ通知を受けるにはホーム画面への追加が必要であるため、アプリは追加の手順を画面で案内する (REQ-TMR-008)。

記録中は画面の消灯を防ぐ仕組みを有効にする。
利用者は設定でこれを無効にできる (REQ-TMR-005)。
ロック画面にタイマーを常時表示する機能は持たず、レストの終了は音、画面表示、プッシュ通知で知らせる (REQ-TMR-004, REQ-TMR-008)。

## Consequences

iOS のプッシュ通知は、ホーム画面への追加、OS の通知許可、端末の状態に依存する。
追加していない利用者には届かないため、音と画面表示を常に代替として持つ。

Service Worker の更新では、古いコードが動き続けないように、更新の検出と再読み込みの手順を持つ必要がある。

ネイティブアプリの常駐タイマーのようには振る舞えない。
画面を消灯した状態での音の再生は保証されず、レスト終了の通知はプッシュ通知に頼る。

単一のコードベースでスマートフォンと PC の両方に配信でき、アプリストアの審査を経ずに更新できる。
