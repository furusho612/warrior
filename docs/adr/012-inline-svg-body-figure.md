# ADR-012: 人体図はインライン SVG と筋肉単位の属性で描く

- Status: Accepted

## Context

すべての種目に、鍛えられる部位を色で示す人体図を表示する。
主働筋と補助筋を区別して示す (LIB-03)。
鍛えられる部位と人体図の色分けは、24 の筋肉の単位で持つ (LIB-12)。
`body-front.svg` と `body-back.svg` は HTML の中に直接書き込んで使う。
`<img>` で読み込むと色を変えられない (design README 「人体図の使い方」)。
主働筋と補助筋は、SVG の属性に筋肉の単位を空白区切りで書く (design README 「人体図の使い方」)。
色は CSS のカスタムプロパティで変える。
指定しなければダークの色になる (design README 「人体図の使い方」)。
独自種目は、部位区分をもとに人体図を示す (LIB-03)。
グリップやアタッチメントに応じて色を変えるのは、研究で違いが確認できた組み合わせに限る (LIB-03)。

## Decision

人体図は、前面と背面の SVG をアプリのバンドルに含め、HTML にインラインで描画する。
画像として読み込まない。

種目が持つ主働筋と補助筋の筋肉の単位を、SVG の `data-primary` と `data-secondary` に空白区切りで設定する。
図の要素は、自分の単位がどちらかに含まれる場合に色を変える。

人体図の色は、テーマごとの CSS カスタムプロパティで指定する。
主働筋、補助筋、それ以外の 3 段階を保つ。

SVG の中の ID は `wfig-` で始める。
前面と背面を同じページに置いても、ID が衝突しないようにする。

独自種目に筋肉の単位がない場合は、部位区分に属する単位をまとめて主働筋として示す。

グリップやアタッチメントによる色の変更は、PRD の「グリップによる色の変更」の表にある組み合わせだけに適用する。
表にない組み合わせでは、グリップを変えても色を変えない。

人体図の外に、主働筋と補助筋の名称を表示する。
色だけで部位を示さない。

## Consequences

SVG をバンドルに含めるため、HTML と JavaScript のサイズが増える。
一方で、画像の読み込みを待たずに人体図を表示できる。

筋肉の単位を追加するときは、SVG の要素、`tokens.json`、種目データを同時に更新する必要がある。
どれかが欠けると、その単位は色に反映されない。

独自種目の人体図は、部位区分の範囲を示す。
実際に効く筋肉の細部は示さないため、種目詳細の文章で補う必要がある。

グリップの例外を種目データに持たせるため、種目マスターの更新と人体図の表示を対応させる必要がある。

色はテーマに依存する。
画面のテーマを変えると人体図の色も変わるため、ライトとダークの両方で主働筋と補助筋の区別を確認する必要がある。
