# ADR-006: 過去の記録は種目と身体情報のスナップショットを持つ

- Status: Accepted

## Context

記録に使われている種目を編集、削除しても、過去の記録は変えない。
マスターの種目も独自種目も同じ扱いとする (REQ-LIB-009)。
マスターの種目も利用者が編集、削除でき、初期の内容に戻せる (REQ-LIB-013)。
身体情報は最新値のみ保持し、推移は記録しない (REQ-PRF-002)。
自重種目の重量は、記録時点の登録体重に加重を足した値である。
記録時点の体重をセットとともに保存し、あとで体重を更新しても過去の記録は変えない (計算ルールと用語定義)。
前回の記録と自己ベストは、同じグリップ、同じアタッチメントの記録を対象にする (REQ-SET-011)。

## Decision

セットの記録は、表示と比較に必要な種目の内容を、記録した時点の値で持つ。
この記録時点の値を **スナップショット** と呼ぶ。
マスターの種目は全体で 1 つの行を持ち、利用者 ID を持たない。
種目 ID は並びと集計のキーとして保持する。
名称、部位区分、主働筋と補助筋、記録方式、左右別の可否、グリップの選択肢は、スナップショットとして保存する。

種目マスターの編集と削除は、利用者ごとの上書きとして保存する。
初期の内容に戻す操作は、その上書きを消す。
過去の記録の表示、自己ベスト、分析は、スナップショットを使う。

自重種目のセットは、記録した時点の体重を保存する。
以後に身体情報を更新しても、そのセットの重量は変えない。

グリップとアタッチメントは、セットの比較キーに含める。
前回の記録、自己ベスト、履歴とグラフの絞り込みは、同じグリップとアタッチメントの記録を対象にする。

削除した種目の ID は再利用しない。
新しい種目に同じ ID を割り当てると、過去の記録が別の種目の履歴に混ざるためである。

## Consequences

同じ内容を種目マスターと記録の両方に持つ。
種目マスターの変更が過去の記録に伝わらないことを、利用者に示す必要がある。

種目マスターの部位区分を変えても、過去の部位別分析は記録時の区分で集計する。
過去の分析値が変わらない代わりに、現在の種目マスターの区分と過去の記録の区分が異なることがある。

種目名を変えても、過去の記録の表示名は変わらない。
同じ種目 ID の履歴に複数の名称が並ぶことがある。

記録時のスナップショットに項目を増やすときは、既存の記録に値を補う移行が必要である。

グリップとアタッチメントごとに自己ベストを持つため、比較の対象を誤らない。
一方で、同じ種目の自己ベストがグリップの数だけ並ぶ。

削除した種目の ID を再利用しないため、ID の採番を管理する必要がある。
