# warrior デザイン

採用したデザインを 1 か所にまとめたフォルダ。
要件は [../prd/warrior.md](../prd/warrior.md) を参照。

画面に出ている数値、種目、日付はすべてサンプルで、実データではない。

## フォルダ構成

```text
docs/design/
├── README.md              この文書
├── tokens.json            配色、フォント、人体図の色、筋肉の単位の一覧
├── screens/
│   ├── dark/              ダークの 11 画面(.png と .html)
│   └── light/             ライトの 11 画面(.png と .html)
└── assets/
    ├── app-icon.svg       アプリアイコン(512 × 512、角丸なし)
    ├── app-icon-512.png
    ├── body-front.svg     人体図の前面
    ├── body-back.svg      人体図の背面
    ├── body-figure-dark.png   人体図の表示例(ベンチプレス)
    └── body-figure-light.png  人体図の表示例(スクワット)
```

- `.png` は 390 × 844 の画面を 2 倍(780 × 1688)で書き出した画像。
- `.html` は同じ画面を単体で開けるようにしたもの。
  スタイルはすべて要素に直接書いてあるので、寸法や色の値をそのまま読み取れる。
  フォントは Google Fonts から読み込むため、表示にはネット接続が要る。
- `.html` どうしは、もとのデザインと同じ場所でつながっている(ホームの「開始」から記録中、記録中の「終了」から終了サマリー、下部のタブなど)。

## 採用した内容

| 項目 | 採用 | 補足 |
| --- | --- | --- |
| アプリアイコン | A 鋼 | 刃のような W。最後の一画だけ色を変えて一段高くしている |
| ホーム | A-1 ダイヤル | 部位ごとの回復状況を輪で示し、中央に「開始」を置く |
| 記録中 | A-4 レール | 左のレールで種目を切り替え、下にレストタイマーを固定する |
| 配色 | 鉄紺 | ダークとライトの 2 つ。値は下の表と `tokens.json` |
| 人体図 | B 鋼・粗め | 筋肉ごとに繊維の向きを線で入れた図。主働筋と補助筋を色で示す |
| セットの種別 | セット詳細の drawer | セット番号を押すと開く。種別と、反動と補助の回数を入れる |

## 画面のきまり

- 基準の大きさは 390 × 844。
  上の 54px は端末の表示領域として空ける。
- 押せる要素は 44px 以上、文字は 11px 以上にする。
- 面やボタンの角は丸めない(ホームの輪と「開始」は除く)。
  面の重なりは影ではなく色の差で示す。
- 記録中の画面は、左に幅 60px の種目レール、下にレストタイマーを固定する。
- セットの表は、ウォームアップを含めて 5 行までスクロールなしで表示する。
  6 行以上は表だけがスクロールする。
- セット番号を押すと、セット詳細の drawer が開く。
  高さは 5 行の表に被らない範囲に収める。
- ドロップセットにした行は、直前のセットに続く段として扱う(PRD の REQ-SET-003)。
  番号の代わりに D を表示し、RPE の欄は持たない。

## 人体図の使い方

`body-front.svg` と `body-back.svg` は、HTML の中に直接書き込んで使う。`<img>` で読み込むと色を変えられない。

主働筋と補助筋は、`<svg>` の属性に筋肉の単位を空白区切りで書く。

```html
<svg class="wfig" data-primary="pec-mid" data-secondary="delt-front triceps" viewBox="0 0 200 440">
  …
</svg>
```

色は CSS のカスタムプロパティで変える。
指定しなければダークの色になる。
ライトでは次の値を、図より外側の要素に指定する。

```css
.theme-light {
  --fig-body: #D3D8DF;
  --fig-tendon: #C8CDD5;
  --fig-rest: #B7BDC6;
  --fig-rest-line: #838992;
  --fig-primary: #9E3E0E;
  --fig-primary-line: #612E18;
  --fig-secondary: #CA957A;
  --fig-secondary-line: #826458;
  --fig-rim: #161B24;
  --fig-rim-opacity: 0.16;
}
```

筋肉の単位は PRD の「筋肉の単位」の 24 個と同じ。

| 部位区分 | 属性に書く名前 | 単位 |
| --- | --- | --- |
| 胸 | `pec-upper` `pec-mid` `pec-lower` | 大胸筋上部、中部、下部 |
| 背中 | `lats` `teres-major` `trap-upper` `trap-mid-lower` `erector-spinae` | 広背筋、大円筋、僧帽筋上部、僧帽筋中部・下部、脊柱起立筋 |
| 肩 | `delt-front` `delt-mid` `delt-rear` | 三角筋前部、中部、後部 |
| 二頭・前腕 | `biceps` `forearm` | 上腕二頭筋、前腕 |
| 三頭 | `triceps` | 上腕三頭筋 |
| 脚 | `quads` `hamstrings` `glute-max` `glute-med` `adductors` `gastrocnemius` `soleus` | 大腿四頭筋、ハムストリングス、大臀筋、中臀筋、内転筋、腓腹筋、ヒラメ筋 |
| 腹筋 | `abs-upper` `abs-lower` `obliques` | 腹直筋上部、腹直筋下部、腹斜筋 |

- 図の中の id はすべて `wfig-` で始まり、前面と背面で重ならない。
  同じページに両方を置ける。
- 左右は同じ形を反転して描いているので、色は左右同時に変わる。
- 色は 3 段階。
  主働筋はいちばん強い色、補助筋はそれより弱い色、それ以外は灰色。

## 未決事項

- アプリアイコンの色は、採用した時点の黒地に橙のまま。
  画面の鉄紺と銅色には合わせていない。
- 種目ごとの補助筋は PRD に定義がない。
  画面に出ている補助筋はサンプル。
- `assets/` のアイコン、人体図、`tokens.json` は、アプリが実際に読み込む素材になる。
  アプリのコードができたら、そちらの置き場所へ移し、このフォルダは参照用にする。
